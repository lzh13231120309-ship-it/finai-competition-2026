# 运行说明

## 本机现有运行环境

原 Windows 应用完整保留在 ../人工智能金融大赛-Windows版。协作仓库不附带大型 runtime，不复制原 data。

在协作仓库目录打开 PowerShell，运行：

```powershell
& '../人工智能金融大赛-Windows版/runtime/python/python.exe' -X utf8 -m server.launcher --port 17901 --no-parent-watch
```

浏览器打开 http://127.0.0.1:17901/ 。该地址只能用于本机演示。运行会在协作仓库内生成自己的 data 文件夹（已忽略）；不要把模型密钥发给同学，用设置页配置个人密钥。停止时在启动终端按 Ctrl+C。

## 同学电脑的新环境（安装流程待实测）

建议 Python 3.13，与现有内置运行时一致。requirements.txt 记录的是从现有环境读取的直接依赖版本，不是完整传递依赖锁文件。

```powershell
python -m venv .venv
& '.venv/Scripts/python.exe' -m pip install -r requirements.txt
& '.venv/Scripts/python.exe' -X utf8 -m server.launcher --port 17901 --no-parent-watch
```

无需激活虚拟环境。创建新环境的安装尚未完成验证，不承诺这些步骤已经在另一台电脑成功。生成 PDF、图表等工具的可选库需要按实际功能补充，现有程序可执行命令的工具本身不保证所有外部依赖都已安装。

为避免修改原个人数据，请不要把 FINAGENT_DATA_DIR 指向原应用 data。本项目面向本地受控演示，现阶段不将服务直接暴露到公网；共享源码与应用部署是两项不同工作。
