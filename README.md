# 金融投研报告核查智能体

四人合作参加 2026 年北京市大学生金融人工智能竞赛。

## 当前状态

共享仓库已创建并验证为私有：[进入团队仓库](https://github.com/lzh13231120309-ship-it/finai-competition-2026)。本项目基于团队已有 Windows 应用源码；另外三位同学的用户名待补，协作者尚未接入。

已确定目标：1 数据结构化提取 → 2 财报分析 → 4 估值建模 → 5 报告纠错核查，通过现有页面展示。第 5 项输入是待核查研究报告草稿，输出是错误清单、原始证据、计算过程和修改建议。

现有应用提供聊天、文件解析、工具与知识库等基础能力；专门金融功能尚未验收。原版本不包含自动扫描 PDF 识别。模型 API 需要各人自行配置。

## 目录

server/：现有 Python 后端；web/：现有 HTML/CSS/JavaScript 页面。保留原布局以兼容代码路径。
docs/：教程、设计和工作报告；samples/：可分享的示例材料；tests/：后续金融功能的核验入口。
.github/：任务和合并请求模板。data/、runtime/、密钥、数据库和本地备份不上传。

## 协作约定

main 保持可运行，个人在 feature/任务名 分支修改，通过 PR 审查合并。禁止上传密钥及个人运行数据。修改前备份、修改后说明检查结果；不得强行覆盖共享历史。

尚未配置强制分支保护；上述目前是团队流程约定。
