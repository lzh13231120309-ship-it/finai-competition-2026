# 单位与量级陷阱

财报提取里**最贵的一类错误是单位错**：它不会报错、不会触发缺失、只会让整表数值
静默地差 1000 倍或 10000 倍，然后污染所有指标、勾稽和估值。

---

## 一、五种口径与换算

| 列报单位 | 换算因子 | 常见场景 |
| --- | --- | --- |
| 元 | 1 | A 股主表通常用元 |
| 千元 | 1,000 | **A 股年报主表最常用**；H 股少数情况 |
| 万元 | 10,000 | 部分 A 股附注、行业统计 |
| 百万元 | 1,000,000 | **H 股 / 港式报表主表最常见**；A 股「财务摘要」页 |
| 亿元 | 100,000,000 | 摘要页、行业数据、媒体口径 |

英制说法要一并识别：`RMB'000` / `RMB in thousands` = 千元；
`HK$ million` / `RMB million` = 百万元；`RMB bn` = 十亿元。

## 二、「多数票」定单位（关键实现纪律）

一张表里出现多种单位声明时，**不能一见两种就判为 unknown**。
判 unknown 会让整表回退到文档级默认单位，那个默认值很可能是错的。

正确做法是**按声明位置收集 + 剔除每股口径 + 多数票**：

1. 用位置化的正则收集所有单位声明：`单位：人民币百万元`、`人民币千元`、
   以及表内末尾以单位结尾的纯数字单元格。
2. **剔除「每股 … 元」里的那个"元"**。每股盈利天然以「元/股」列报，
   与报表列报单位无关，具体特征词：`每股`、`每股盈利`、`每股收益`、`每股股息`、
   `earnings per share`、`per share`、`EPS`。
   判断时看声明位置前后 60 个字符。
3. 对剩下的声明做**多数票**：出现次数最多的单位胜出；
   **只有并列第一才判 unknown**。
4. 币种逻辑独立：出现两种以上币种才判 unknown，单一币种胜出，识别不出默认 CNY。

### 实测踩过的坑

农夫山泉 9633.HK 年报第 11 页「五年財務摘要」：
元数据里同时出现 `人民幣百萬元` 和 `每股基本盈利 … 人民幣元`。
旧逻辑"见多单位即 unknown"→ 整表退回文档级默认「千元」→ 该页所有数值放大 1000 倍
→ 引出 `roa = 268`、`asset_turnover = 838` 这类荒谬指标，以及 4 项勾稽失败。
改为剔除每股行 + 多数票后，该页正确判为「百万元」。

**识别信号**：如果某张表算出来的 ROA、资产周转率、毛利率量级明显荒谬
（如 ROA > 100、资产周转率 > 10），**第一个要怀疑的就是单位，不是财务造假**。

## 三、摘要页 vs 主表的量级差

年报的「財務摘要 / 主要財務數據 / 五年財務摘要 / FINANCIAL HIGHLIGHTS」页
通常以**百万元列报并四舍五入到整数**，而主表用**千元精确值**。
两者对同一科目天然会有几万元到几十万元级的差。

这不是数据错误，是**列报精度差**。处理方式：

- 摘要页的事实打标 `source_tier = 'summary'`，主表打 `source_tier = 'primary'`。
  完整的三档分级（`primary` > `summary` > `inferred`）见
  「03-港式H股与英文报表识别.md」第九节。
- 同一科目出现两个值且来源等级不同时，**先比舍入量子**：
  `容差 = 舍入量子(摘要值) × 2 + 舍入量子(主表值) × 2`。
  在容差内视为一致，记 `cross_check`；超出容差才判真冲突，且**只降级低档那一侧**，
  基准档数据保持可用。
- **绝对不要用相对百分比做容差兜底。** 1‰ 的百分比容差会把 5200 万的真实差异
  当成"四舍五入"放过。法证工具一旦这样放宽就失去意义。

为什么要保留摘要页数据：它是**唯一提供 5 年跨度**的地方。
缺了它，持续性与趋势类规则只剩两年可比，`persistence` 因子直接失效。

## 四、单位错位反查（勾稽失败的第一预案）

会计恒等式不成立时，**先怀疑单位、口径、期间，再怀疑数据本身**：

1. 单位（元/千元/万元/百万元/亿元）
2. 口径（合并 / 母公司）
3. 期间（时点值 vs 区间值）

引擎会做**单变量数量级替换**反查：尝试把某个科目乘以/除以 1000、10000 等，
看恒等式是否在容差内成立。结果写在 `tieout_diagnosis` 里：

- 有唯一解 → 给出建议的单位量级与依据，例如 `resolution: unit_misplacement`。
  **写明建议，但不要自动改数。**
- `ambiguous` → 表示多个科目同时错、必须转人工，不要硬猜。

## 五、会计恒等式的容差

容差必须**随单位和四舍五入调整**，不能写死一个绝对值。
量级用舍入量子（即该单位的 1 个最低有效位，或由数值的位数推出）来定，
避免"以元列报的报表"和"以百万元列报的报表"用同一个容差。

## 六、数值解析的护栏

- 括号 = 负数：`(1,234)` = −1234。
- 破折号/短横 = 零或无数值：`—`、`-`、`–`。**不要当 0 参与计算**，应视为缺失。
- 千分位分隔符混用：`1,234,567` 与 `1 234 567` 与 `1.234.567` 都要处理。
- **位数上限**：解析出的整数部分超过 15 位应拦下（超过 `Decimal` 精度且必然是解析错误，
  例如把附註编号与数值粘在一起）。
- 「附註 / Note」列的编号**不是数值**。识别科目行时若该行只有附註编号和科目名、
  没有真实金额，不应产出事实——构造测试数据时也要避免把附註号当金额
  （实测踩过：`15` 被当成数值）。
