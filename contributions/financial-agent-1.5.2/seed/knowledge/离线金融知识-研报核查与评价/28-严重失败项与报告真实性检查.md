# 严重失败项与报告真实性检查

真实性问题需要与一般计算错误区分。伪造不存在的来源、篡改原文、冒用作者身份或把未取得的材料说成已经核验，会破坏证据链。不能只因网页无法访问就认定伪造，也不能因为来源链接存在就确认所引内容真实。真实性检查应核对文件与来源内容对应关系。

操作程序：建议内部设置严重失败项：已确认伪造关键来源，已确认篡改关键证据，核心估值建立在重大不可复算数据且无任何替代依据，或将实际无法核验写成已验证。对前三类先说明确认依据和影响范围；对仅缺材料的情形使用“阻断评价、待补材料”，与“已确认造假”分开。

合成例：报告引称“年报第18页收入100亿元”，原年报第18页实际为90亿元。先核对版本、期间、合并范围和单位；全部相同后可以确认引用不一致。仍需区分误引、录入差错与有意篡改，有意性没有证据时不得定性。无法下载年报只说明来源未取得。

边界与输出：严重失败不一定使所有部分无价值，但总评应明显提示关键结论不可依赖，并禁止由其他高分抵销真实性破坏。原始文件哈希可检测本地变化，却不能证明发布者身份。建议保存原文件、获取路径、取得时间和核验日志；对可信电子签名或正式披露渠道按实际证据记录，不声称完成了不存在的数字签名认证。

核查留痕要求：上述程序是本库针对离线核查提出的操作建议，不是所列来源逐条规定。每次使用需登记被核查报告版本、相关主张编号、原文件页码、支持与反证、执行步骤、结果状态以及尚缺材料。若证据只能证明“发布者作出该陈述”，就不要扩展为“经济事实已被独立验证”。合成例仅用于测试流程，不能作为真实公司、真实市场或赛事事实检索。

复核验收：验收重点：严重失败有可定位的确认依据，失效链接与伪造来源没有混用。对原始文件不一致，先排除版本、下载和OCR问题。证据有意性通常超出普通离线核查权限，结论应止于已确认差异。若发现来源哈希改变，保存两个版本并比较具体内容；仅哈希不同不能判断哪一个真或假。
