# 定期报告取数地图

同一份年报里，同一个指标往往出现在三四个位置，而**这些位置的数字并不总是一致**。
取数地图要解决的不是"找不到数"，而是"找到数之后知道该用哪一个、以及不一致时怎么解释"。

## 一、年报的章节结构与取数入口

| 章节 | 提供什么 | 取数价值 |
| --- | --- | --- |
| 重要提示、目录和释义 | 审计意见类型、董事会声明、简称对照 | 判断是否标准无保留意见；简称映射 |
| **公司简介和主要财务指标** | 主要会计数据与财务指标表：营业收入、归母净利润、扣非归母净利润、经营活动现金流净额、基本每股收益、加权平均净资产收益率、总资产、归母净资产 | **最快的汇总入口**，但见第三节的"不一致"陷阱 |
| 管理层讨论与分析（MD&A） | 分行业/分产品/分地区收入与成本、毛利率、研发投入、现金流分析、资产构成变动、主要子公司 | 唯一能拿到**分部与结构**数据的地方；管理层口径 |
| 公司治理、环境和社会责任 | 治理结构、董监高薪酬、环保与社会责任 | 治理类结论的依据 |
| 重要事项 | 诉讼、担保、关联交易、承诺履行、处罚 | 或有事项与表外义务线索 |
| 股份变动及股东情况 | 股本结构、前十大股东、质押冻结 | 股数（每股指标的分母）、控制权 |
| **财务报告** | 审计报告 + 三大报表 + 附注 | **法定数据源**；报表正文用于取数，附注用于明细与口径 |

## 二、三类报告的信息密度差异（决定"能不能取到"）

| 报告 | 财务数据要求 | 是否审计 | 含附注 | 取数含义 |
| --- | --- | --- | --- | --- |
| **年报** | 完整三大报表 + 完整附注 + 主要会计数据表 + 完整 MD&A | 需审计 | 完整 | 绝大多数科目与明细都能取到 |
| **半年报** | 三大报表 + 附注（可依重要性简化）+ MD&A | 视情况审计或审阅 | 简化 | 多数科目可取，冷门附注明细可能缺失 |
| **季报** | 主要会计数据与财务指标 + 财务报表（可简化） | **不要求审计** | **通常不含完整附注** | 取数面最窄：只能拿到主要科目与少数重要事项 |

**这条差异直接决定"数据缺口"怎么表述**：
季报里取不到"应收账款账龄明细"，不等于"公司没披露"，而是**该报告类型不要求披露**——
正确写法是"该明细见最近一期年报（第 N 页）"，而不是"未披露"。

## 三、同一指标的多处出处与优先级（本条目最重要的一节）

同一个"营业收入"在年报里至少出现在：主要会计数据表、MD&A 分产品表、利润表、附注"营业收入"明细。

**优先级**：**经审计的财务报表正文 > 财务报表附注 > 主要会计数据表 > MD&A 叙述**。

**为什么主要会计数据表可能和财务报表对不上**：当公司发生**同一控制下企业合并**或**前期差错更正**时，
主要会计数据表里的"上年同期数"会被**追溯重述**，而上年实际披露的原始报告里是重述前的数。
两者都是"真实披露过的数字"，混用就会造出一个不存在的增长率。

处理规则：
1. 增长率必须**在同一份报告内**用同一次披露的两个数计算（本期数 ÷ 本期报告列示的上年同期数）。
2. 需要跨报告比较时（如"2025 年报数 vs 2026 半年报的上年同期数"），先核对是否重述；
   不一致就在报告里写明"存在追溯重述，两期数字不可直接比较"，**不得静默选一个**。
3. 主要会计数据表与财务报表正文不一致时，**以财务报表正文为准**，并说明差异原因。

## 四、逐项取数定位速查

| 要取什么 | 首选位置 | 备选/补充 | 典型陷阱 |
| --- | --- | --- | --- |
| 营业收入 / 营业成本 | 合并利润表 | 附注"营业收入和营业成本"（分产品/地区） | 区分"营业收入"与"营业总收入"；金融企业口径不同 |
| 归母净利润 | 合并利润表 | 主要会计数据表 | 与"净利润"差少数股东损益；与"扣非归母"差非经常性损益 |
| 扣非归母净利润 | 主要会计数据表 / 附注"非经常性损益" | — | 附注给出非经常性损益逐项明细，是**唯一**能取到明细的位置 |
| 经营活动现金流净额 | 合并现金流量表 | MD&A 现金流分析 | 与净利润的差异要解释，不能直接说"质量差" |
| 总资产 / 归母净资产 | 合并资产负债表 | 主要会计数据表 | 与母公司报表的数不同 |
| 基本每股收益 | 合并利润表（每股收益项） | 附注"每股收益" | 与"稀释每股收益"不同；分母是加权平均股数 |
| 加权平均 ROE | 主要会计数据表 | 附注"净资产收益率" | 与"期末净资产/净利润"算出的简化 ROE 不同口径 |
| 股本 / 总股数 | 股份变动章节 / 资产负债表"股本" | 附注 | 股本是面值总额（元），**不是股数**；股数 = 股本 ÷ 每股面值（通常 1 元） |
| 有息负债 | 资产负债表（短期借款、长期借款、应付债券、一年内到期非流动负债） | 附注 | 租赁负债是否计入有息负债须声明口径 |
| 折旧摊销 | 现金流量表补充资料 | 附注"固定资产/无形资产" | 补充资料里的"固定资产折旧"与附注的"本期计提折旧"口径可能不同 |
| 分部收入 | 附注"分部报告" | MD&A 分行业/分产品表 | MD&A 是管理层口径，与分部报告的分部划分可能不同 |
| 前十大股东持股 | 股份变动及股东情况 | — | 限售/流通、质押/冻结要分别看 |

## 五、合并报表与母公司报表

年报的财务报告部分通常**同时列合并报表与母公司报表**（母公司报表在合并报表之后，
或在附注"母公司财务报表主要项目注释"里）。

- 取数前必须声明用**合并**还是**母公司**口径。
- 母公司报表只反映母公司法人主体，不含子公司——用母公司数算合并层面的比率会系统性偏离。
- 归母净利润来自**合并**报表（"归属于母公司所有者的净利润"），不是母公司报表的净利润。
- 附注编号容易看错："合并财务报表项目注释"下的数是合并口径；
  "母公司财务报表主要项目注释"下的数是母公司口径，**两者不能混用**。

## 六、操作检查

1. 取数前先确定：报告类型（年报/半年报/季报）、期间、合并或母公司、币种、单位。
2. 单位逐表核对：同一份报告里不同表可能用不同单位（元 / 千元 / 万元），
   不能只在报告开头看一次就套用到全篇。
3. 增长率在同一份报告内计算；跨报告比较先查重述。
4. 附注编号与章节号不是数值（`五、` `8.` 都不是金额）。
5. 表格里的 `—` 是"无此项/不适用"，填 `null`，不当 0 参与计算。
6. 追溯调整、会计政策变更、同一控制下合并，都会造成"数字变了但不是经营变化"，
   必须在报告里单独说明，不能混进经营分析。

## 七、交付检查

- 每个取到的数都写清：报告类型 + 期间 + 章节/表名 + 页码 + 合并或母公司口径。
- 分部数据写明来源是"附注分部报告"还是"MD&A"，两者不可混引。
- 出现重述或口径变化时，明确写"存在追溯重述/口径变化，两期不可直接比较"。
- 季报取不到的明细，写"见最近一期年报（第 N 页）"，不写"未披露"。
- 股数取数写明是"股本（元）÷ 每股面值"推算还是直接披露，**推算值要标注为推算**。
