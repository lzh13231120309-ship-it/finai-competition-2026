# 一手方法与开源来源

检索日期：2026-10-10。本技能的中文说明为原创摘要；公司输入仍须引用公司证据。

- [NYU Stern：终值与超额收益](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)：稳态增长、再投资和 ROIC 联动。
- [NYU Stern：金融服务企业估值](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/finfirm.pdf)：银行直接股权估值，DDM/超额收益及资本留存。
- [NYU Stern：资本成本与 β 常见问题](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/project/prques.htm)；[估值币种与风险输入](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/eqUGemailSpr25.html)：历史窗口与币种纪律。
- [NYU Stern：同行差异控制](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/controldifferences.htm)：增长、风险及现金流可比。
- [NYU Stern：Growth Origins](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/growthorigins.pdf)：市场价格隐含增长的条件解释。
- [FinanceToolkit固定提交](https://github.com/JerBouma/FinanceToolkit/tree/a232ddf84d4bb2da17e5385b7862873b6943c2a8)：透明的 WACC/DCF/RI公式对照；[MIT许可](https://github.com/JerBouma/FinanceToolkit/blob/a232ddf84d4bb2da17e5385b7862873b6943c2a8/LICENSE.txt)。本技能未复制其源码，未引入数据服务依赖。

以上资料不提供本次具体公司的2026年实时股价、利率、β或ERP。公开可读不是教材再分发许可；引用方法不授权采集或再分发行情数据。
