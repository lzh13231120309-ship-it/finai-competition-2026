# 比率与每股指标陷阱

金额类科目之外，还有两类**不是金额**的数值：**每股指标**和**比率**。
它们不遵守"千元/百万元"的缩放规则，被当成金额处理后会产生荒谬结果。

---

## 一、每股指标：单位是「元/股」，不是元

`basic_eps`（基本每股盈利）、`diluted_eps`（稀释每股盈利）、
`dividend_per_share`（每股股息）的单位是 **`元/股`**。

它的量级由"股"决定，与报表列报单位（千元 / 百万元）**完全无关**。

### 实测踩过的坑

农夫山泉 9633.HK 2025 年报：基本每股盈利 = **1.411 元/股**。
提取环节本身是对的（`value_unit: CNY/share`），但报告环节把它当金额做了
「元 → 千元」换算：

```
1.411 ÷ 1000 = 0.001411 → 四舍五入两位小数 → 0.00
```

报告里于是出现「每股收益 0.00 元」，读者会以为公司几乎不赚钱。

### 规则

- 每股类指标**不参与任何单位换算**。它的 `unit` 恒为 `元/股`（或 `CNY/share`）。
- 每股类指标**不能与金额相加**。`EPS × 股数 = 归母净利润` 是恒等式，
  但前提是股数用**股**、净利润用**元**——不能一边千元一边元。
- 报表列报单位的"多数票"统计里，**必须剔除「每股 … 元」的那个"元"**，
  否则会把整表的单位判错（详见「01-单位与量级陷阱.md」第二节）。

## 二、比率：单位是 `ratio`，值是比例小数

毛利率、净利率、资产负债率、ROE、ROA、周转率、现金转化率这类指标的
`unit = ratio`，值是**比例小数**：

| 存储值 | 正确表述 | 错误表述 |
| --- | --- | --- |
| `0.6053` | 60.53% | 6053% ❌ / 0.6053 元 ❌ |
| `0.3943` | 39.43% | 3943% ❌ |
| `1.3323` | 133.23% | 133.23 千元 ❌ |

**任何比率都不得按千元/百万元缩放。** 缩放比率在数学上没有意义，
但因为它"看起来是个数"，极易被顺手套用单位换算。

周转天数类指标的 `unit = days`，直接是天数，同样不参与金额缩放。

## 三、量级自查：什么时候该怀疑单位而不是怀疑公司

算出下列结果时，**第一反应必须是"单位错了"**：

| 异常结果 | 更可能的真实原因 |
| --- | --- |
| ROA > 100 | 分子分母单位不一致（一个千元一个元） |
| 资产周转率 > 10 | 同上；或分母用了期末单点且规模被低估 |
| 毛利率 > 100% 或 < 0 | 成本与收入口径不同（含/不含税、含/不含其他业务） |
| 每股收益 0.00 | **EPS 被当成金额做了千元换算** |
| 净现金 > 总资产 | 类现金口径放宽（把理财计入）或有息负债漏算 |
| 折旧摊销 = 8 或 15 | 附註编号 / 章节编号被当成数值 |

**判据**：先在 `facts` 里查该科目的**原文单位**与**原文数值**，
用原文数字手算一遍。原文对而指标错 → 是口径/换算问题；原文就错 → 才是抽取问题。

## 四、跨表指标的分母纪律

周转率、ROE、ROA 的分子是**区间值**（利润表/现金流量表），分母是**时点值**
（资产负债表），所以分母必须用**期初期末平均**：

```
平均余额 = (期末余额 + 期初余额) / 2     其中 期初 = 上年 12-31
```

- 用**期末单点**做分母会系统性偏高（期末资产规模通常大于年初），
  得出的 ROE、周转率会偏低——而且是"看起来合理"的偏低，不会报错。
- **期初值缺失时不得用期末值代替后仍称"平均"**。应改标"期末口径"或列为待复核。
- 半年报/季报的周转类指标**不做年化**，公式里写明 `period basis, not annualized`，
  并把区间实际天数写进公式。把半年周转天数 × 2 当全年，是常见但无依据的做法。

## 五、增长率的正负号陷阱

- 同比公式 `(本期 − 前期) / 前期` **只在前期为正时**有意义。
- 前期为**零**：无法按普通公式计算，应写明"前期为零，同比不可比"。
- 前期为**负**：套普通公式会得出"增长 −200%"这种误导性结果。
  应改写为**增亏 / 减亏 / 扭亏** + 绝对差额。
- 增速的**基数是负或零**时，工具会给出说明；报告不得沿用普通同比结论。

## 六、交付前的三条硬检查

1. 报告里出现的每一个百分数，都能在指标表里找到对应的 `ratio` 原值。
2. 报告里出现的每一个"元/股"，都没有被任何换算因子乘除过。
3. 所有周转率、ROE、ROA，分母都是平均值，或明确标注为期末口径。
