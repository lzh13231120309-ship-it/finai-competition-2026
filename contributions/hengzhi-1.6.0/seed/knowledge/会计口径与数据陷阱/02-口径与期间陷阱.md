# 口径与期间陷阱

单位之外，另外两类会让数据静默错掉的问题是**口径**（谁的数据）和**期间**（哪一段的）。
本文件记录实际踩过并修好的四类陷阱。

---

## 一、列 → 期间的映射：双列表格必须用"自家表头"

一张资产负债表通常列示"本期期末 + 上期期末"两列（或"本期 + 上年同期"）。
提取时把哪一列映射到哪个期间，决定了全部事实的期间标签。

**错误做法**：从左到右逐个填期间，遇到没有表头的列就无条件向左继承。
后果：双列表中的"2024年"列被补上左邻的"2025"，于是**所有表格的前一期数据
被错标成最新期，而且不会报任何错**。这是影响面最大的一类缺陷。

**正确做法**：
- 每一列先看**本列自己有没有表头标签**（年份、日期、`2025年12月31日`、
  `截至2025年12月31日止年度`、`31 December 2025`）。
- 本列有自家标签 → 用自家标签。
- 本列标签为空 → 才继承左邻。
- **附註列（Note 列）永远不作数值列**。

**校验手段**：勾稽恒等式里的「期初值 = 上年期末值」。
如果实现正确，`cash_equivalents_rollforward` 这类检查会通过；
如果期间错标，相邻两期数据会互相矛盾而勾稽失败——这是最好的回归探针。

## 二、口径（scope）：合并 vs 母公司

- **合并报表（consolidated）**：集团口径，含子公司。分析默认口径。
- **母公司报表（parent）**：单体口径，只含母公司本身。

单体报表与合并报表**科目名完全相同**，判错就全盘错。识别优先级：

1. **最强信号**：`本公司…表` / `母公司…表` / `the Company statement of ...`
   → 直接判 `parent`。中文常见写法：`母公司资产负债表`、`母企业利润表`。
2. `合并…表` / `合并及公司…` / `Consolidated statement of ...` → `consolidated`。
3. 英文/港式：`Consolidated statement of financial position` = 合并；
   `the Company statement of ...` = 单体。
4. 识别不出时不猜：返回 `unknown`，并把该表排除或交人工。

**严格分开的要求**（竞赛原文）：合并口径与母公司口径必须严格分开。
请求口径与表格明确口径不符时，应**过滤该表并记警告**，而不是混在一起算。

口径冲突时（请求公司 ≠ 来源披露公司，或来源身份有多个），保留来源身份并加入复核队列。

## 三、口径继承：摘要页的特殊处理

「財務摘要 / 主要財務數據 / 主要会计数据 / 五年財務摘要 / FINANCIAL HIGHLIGHTS」
这类页面**没有报表标题**，逐表判定必然是 `unknown`，于是整页数据被排除。

但这类摘要**按定义就是集团合并口径**，而且是唯一提供 5 年跨度的地方。
所以：摘要页在 `unknown` 时**继承 `consolidated`**，并打 `scope_inherited = true` 标记，
让它能被审计到"这是继承来的口径，不是原文明示的口径"——而不是静默当成主表数据。

## 四、分节（section）：同名科目在流动/非流动下各列一次

财务状况表里，`租賃負債`（租赁负债）会在**流动负债**和**非流动负债**下各列一次，
两个数值不同却同名。只按科目名匹配时它们会互相冲突，**把两张表的数据一起打成不可用**。

处理方式：
1. 识别分节标题行：`流動資產 / 流动资产 / Current assets`、
   `非流動資產 / 非流动资产 / Non-current assets`、
   `流動負債 / 流动负债 / Current liabilities`、
   `非流動負債 / 非流动负债 / Non-current liabilities`。
2. **分节标题的识别必须放在科目识别之前。**
   因为 `流動負債` 本身就是 `current_liabilities` 的别名——
   若先走科目匹配，这一行会被当成科目而非分节，
   随后的 `租賃負債` 就永远分不出即期/非即期。（实测踩过：分节从未生效。）
3. **只有该行不含任何数值时**才认定为纯分节标题行。
4. 按分节把科目拆成独立代码：

| 原科目 | 流动负债下 | 非流动负债下 |
| --- | --- | --- |
| `lease_liabilities`（租赁负债） | `lease_liabilities_current` | `lease_liabilities_noncurrent` |
| `borrowings`（計息借貸） | `short_term_debt` | `long_term_debt` |

注意第 4 条对 `borrowings` 的拆分：港式报表常只列一个「計息借貸」总额，
按分节拆开后正好变成 A 股习惯的「短期借款 / 长期借款」——
这直接决定了净债务能不能正确取到（见 DCF 的净债务桥接）。

## 五、时点值 vs 区间值

- **instant（时点值）**：资产负债表科目，如 `assets`、`cash`、`equity`。
  期间标签是"某一天"，如 `2025-12-31`。
- **duration（区间值）**：利润表与现金流量表科目，如 `revenue`、`net_profit`、
  `operating_cash_flow`。期间标签是"某一段"，如 `2025-12-31` 代表 2025 全年。

**汇率折算、周转率、ROE/ROA 这类"跨表"指标必须成对使用同类型数据**：

- 周转率与 ROE/ROA 的分子是区间值、分母是时点值，所以分母要用
  **期初期末平均**：`(期末 + 期初) / 2`，其中期初 = 上年 12-31。
- 不要用期末单点做分母——那会系统性偏高（期末资产规模通常大于年初）。
- 报告期不足一年时（如半年报），周转类指标**不做年化**，公式里明确写
  `period basis, not annualized`，并把"期间天数"写进公式。

## 六、重述与追溯调整

- 报表含 `重述 / 追溯 / 调整后 / 重分类` 字样时，**该表不能直接与未重述的表相减**。
- 重述数据必须**标记版本**，且**优先使用重述口径**。
- 推算单季数据时，如果本期与上期的重述标记不一致（一个重述了、一个没有），
  **不相减**，直接进入复核队列（`restatement_mismatch`）。
- 单季推算值与单季披露值冲突时不选择任何一方，进入 `quarter_conflict` 复核。

## 七、前视偏差（分析截止日）

- 所有查询都带 `analysis_cutoff`；**发布日晚于截止日的文档不进入检索**。
- 行情与同行倍数按截止日快照存储；**禁止用当前值回填历史分析**。
- 演示标的选定后**冻结分析截止日**，确保现场出现的所有信息都早于该日期。
