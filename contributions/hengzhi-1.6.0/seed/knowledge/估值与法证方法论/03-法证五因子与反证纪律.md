# 法证五因子与反证纪律

## 一、风险评分（排序工具，不是概率）

```
risk_score = 0.30 × magnitude
           + 0.25 × persistence
           + 0.20 × peer_extremeness
           + 0.15 × cash_impact
           + 0.10 × disclosure_uncertainty
```

每项归一到 **0–100**，分数越高风险越大。
**评分只用于排序，不直接等同于舞弊概率。**

| 因子 | 含义 | 取值要点 |
| --- | --- | --- |
| `magnitude` | 幅度：偏离阈值多少 | 偏离一个 `span` 记满分，只算**超出阈值**的部分。阈值内不生成发现 |
| `persistence` | 持续性：连续多少期成立 | `连续期数/3 × 100`，**最多回溯 3 年且逐年真实命中**。单期异动得分天然低 |
| `peer_extremeness` | 同行极端程度 | 偏离同行中位数的相对幅度。**没有同行数据取中性 50 并标记 `peer_data_missing`** |
| `cash_impact` | 现金影响 | 只对**真正影响现金流或净资产**的规则加权（100），其余 40 |
| `disclosure_uncertainty` | 披露不确定度 | 依赖事实无证据编号 +1.0，置信度 < 0.9 再 +0.5，除以依赖数 |

`cash_impact` 加成规则：应收、存货、经营现金流背离、收现比、
经营现金流恶化、短债缺口、资本开支、关联方资金占用。

### `disclosure_uncertainty` 的解读要小心

"说不清本身就是风险"，但也可能只是**披露简略**。
必须在交付物里区分两者——不要把"这家公司披露风格简洁"写成"刻意隐瞒"。

### severity 分档（由 risk_score 推出）

| 分数 | severity |
| --- | --- |
| ≥ 75 | critical |
| ≥ 55 | high |
| ≥ 35 | medium |
| < 35 | low |

**severity 直接决定估值压力幅度**（critical 1.0 / high 0.7 / medium 0.4 / low 0.15 的权重），
所以严重度标错会改变估值结论。这要求逐条复核严重度，不是机械接受引擎输出。

## 二、发现合并

同一 `rule_id` + 同一公司 + 同一口径，跨年命中**合并成一条**：

- `periods` 列出所有命中年份；`consecutive_periods` 取最大连续期数。
- 代表值（`severity` / `risk_score` / `detail`）取**分数最高那一期**。

不合并的话 Top 10 会被同一规则的三个年份挤满，排序失去信息量。

## 三、反证是一等公民，不是补充

**每条发现都强制带两份东西**：

| 字段 | 内容 |
| --- | --- |
| `counter_checks` | **反证检索方向**——能推翻这条发现的检索线索 |
| `open_questions` | **还没解决的问题**——必须回附注/管理层讨论/关联方与分部信息去查 |
| `valuation_links` | 这条风险传导到哪个估值参数 |

**必须真的去查**，并把结论写进交付物——**包括"查了、但没找到解释"这种结果。**

典型反证方向举例：

| 规则 | 替代解释 |
| --- | --- |
| `R_AR_01` | 业务季节性、结算方式变化（现款转月结）、票据重分类、并购导致合并范围变化、信用政策放宽但有合同依据 |
| `R_INV_01` | 为预期订单提前备货且有在手订单支持、原材料涨价导致战略囤货、产品结构调整 |
| `R_CFO_01` | 收入与回款跨期错配（政府客户年末结算）、票据结算比例上升、大额预付款占用 |
| `R_MARGIN_01` | 产品结构升级且均价可验证、原材料价格下行传导、产能利用率提升摊薄固定成本、会计政策变化 |
| `R_DEBT_01` | 存在未使用的银行授信额度、债务期限结构在期后已置换为长期 |
| `R_CAP_01` | 处于行业景气周期中的产能扩张期（有募投项目与进度披露）、在建工程集中转固、并购整合资产重估 |
| `R_RPT_01` | 集团内正常资金池调剂且已披露、已按期偿还的历史往来款、预付款对应真实的大宗采购锁价 |
| `R_TIEOUT_01` | 四舍五入差异在容差内、重述口径未统一、合并与母公司口径混用 |

**遗漏反证是矛盾分类里的一类**（"遗漏反证"）：只引用管理层解释、忽略现金流恶化，
由 Critic 强制加入反证检索。

## 四、证据分级与发现的绑定

- 每条发现必须至少有一个 **E1 或 E2** 证据（方案的质量门要求）。
- 依赖事实的 `evidence_ids` 为空会推高 `disclosure_uncertainty`——
  这本身就是信号：**算出来但说不清从哪来**。
- E3（模型推断）必须展示推理和反证；E5（无外部证据）**不得进入最终结论**，
  只进入待核验列表。

## 五、四个必须完成的勾稽测试（与发现的关系）

1. 资产负债表恒等式在容差内成立。
2. 现金流量表现金净增加额与资产负债表货币资金变动**解释性对账**。
3. 利润表净利润与现金流量表**间接法起点一致**或能由少数股东口径解释。
4. **各年期初值与上年期末值一致**；重述数据优先使用重述口径。
5. **合并与母公司口径严格分开**；单位全部换算到标准单位。

勾稽失败由 `R_TIEOUT_01` 承接，并做**单变量数量级替换反查**：

- 唯一解 → `resolution: unit_misplacement`，给出建议单位量级与依据（分数固定 90）。
- 多解 → `resolution: ambiguous`，**表示多个科目同时错，必须转人工**（分数 65）。
- 无法解析公式 → `resolution: undetermined`，转人工。

**绝不自动改数。** 系统只提示，人工确认后才改。

## 六、矛盾分类（文本层）

| 类型 | 例子 | 处理 |
| --- | --- | --- |
| 数字矛盾 | 正文称收入增长，事实表显示同比下降 | **E1 数据优先**，标记文本冲突 |
| 时间矛盾 | 用下一年度解释回填到上一时点 | 按截止日屏蔽后发信息 |
| 口径矛盾 | 公司用调整后利润，同行用法定净利润 | **不直接比较**，显示口径差异 |
| 因果不足 | 把相关性描述为成本下降的原因 | 降级为假设并寻找外部价格证据 |
| 遗漏反证 | 只引管理层解释，忽略现金流恶化 | Critic 强制加入反证检索 |
| 来源等级冲突 | 新闻传闻与法定公告不同 | 法定披露优先，**保留冲突记录** |

## 七、交付物必须包含的内容

1. **运行 ID**，以及完整清单的读取方式（`read_financial_run(section='findings')`）。
2. **样本与口径**：公司、期间、合并/母公司、币种与单位。
3. **命中的规则与排序**（按 `risk_score` 降序，含 `rank`）。
4. **每条的评分分解**（五个因子分别多少）。
5. **支持证据 ID** 与**依赖事实 ID**。
6. **反证检索结果**（真的查了什么、查到什么、没查到什么）。
7. **未解问题**（`open_questions`）。
8. **传导到的估值参数**。
9. **明确的"未覆盖范围"**——哪些指标模块因为缺少附注数据没有实现
   （如账龄结构、客户集中度、研发资本化率、跌价准备覆盖率、净债务/EBITDA 等）。

## 八、语言纪律（合规红线）

- 用"**待核验事项**""**需要解释的差异**"，
  **不要用"造假""舞弊"**。
- 每条发现都带 `disclaimer`：
  "这是需要人工核验的风险信号，不是财务造假结论。"
- 不要为了填满报告而降低阈值或重复计数。**允许并鼓励"未发现异常"的结论。**
- 报告四维度一票否决：关键数字错误、伪造引用、三表不平或因果倒置、
  收益保证或确定性荐股、只有摘要没有决策支持。
