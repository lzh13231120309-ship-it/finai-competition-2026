# DCF 建模纪律与边界

## 一、核心公式（方案原文）

```
FCFF   = EBIT × (1 − tax_rate) + 折旧摊销 − 资本开支 − ΔNWC
EV     = Σ FCFF_t / (1 + WACC)^t  +  TerminalValue / (1 + WACC)^n
Equity = EV − 净债务 − 少数股东权益 + 非经营性资产
TV     = FCFF_{n+1} / (WACC − g)          # Gordon 增长模型
```

相对估值（PE、EV/EBITDA、PB）**只与业务模式和口径相近的同行比较**。

---

## 二、业务驱动，不做单变量外推

预测以**驱动变量**为主，不直接对净利润做外推。每个假设都要记录
**基准来源、历史范围、同行范围、情景差异和负责人**。

| 模块 | 驱动变量 | 联动结果 |
| --- | --- | --- |
| 收入 | 销量、单价、产能利用率、产品结构 | 营业收入与合同负债 |
| 毛利 | 售价、原材料、良率、产品结构 | 毛利率与存货 |
| 期间费用 | 费用率或人数与薪酬 | 营业利润与现金支出 |
| 营运资本 | 应收天数、存货天数、应付天数 | **经营现金流** |
| 资本开支 | 扩产计划、维持性资本开支 | 固定资产、折旧与投资现金流 |
| 融资与税 | 债务计划、利率、有效税率 | 利息、税费、净债务 |

MVP 预测 **3 年**、按年度建模；若演示标的季节性强，再增加季度桥接。

## 三、`ΔNWC` 的正确口径

```
nwc_days = receivable_days + (inventory_days − payable_days) × (1 − gross_margin)
ΔNWC_t   = revenue_t × nwc_days / 365  −  revenue_{t−1} × nwc_days / 365
```

**第 1 年的 `ΔNWC` 只计增量，不是全量营运资本占用。**
期初营运资本已经在基期资产负债表里，重复计入会双重扣减 FCFF。
正确的做法是把 `prev_nwc` 初始化为 `revenue_0 × nwc_days / 365`。

### 为什么存货与应付天数要先乘 (1 − 毛利率)

三项周转天数的分母并不相同：

```
应收周转天数 = 期间天数 × 平均应收账款 / 营业收入
存货周转天数 = 期间天数 × 平均存货     / 营业成本
应付周转天数 = 期间天数 × 平均应付账款 / 营业成本
```

把三者直接相加再乘收入，等于默认存货与应付也用收入作分母，
会把营运资本占用放大 **1/(1 − 毛利率)** 倍。

实测（某公司真实数据）：净营运资本真值 44.2 亿元（占收入 **8.41%**），
用"直接相加"算成 103.5 亿元（占收入 **19.69%**），
ΔNWC 随之虚增一倍以上，FCFF 与估值被系统性压低。

推导：设期间天数 D，收入 R，营业成本 C，毛利率 m（C/R = 1 − m）。

```
NWC = 存货 + 应收 − 应付
    = (inventory_days × C + receivable_days × R − payable_days × C) / D
    = R/D × [ receivable_days + (inventory_days − payable_days) × (1 − m) ]
```

报告里引用营运资本假设时，请引用引擎给出的 `nwc_days_revenue_basis`
与 `nwc_to_revenue`，**不要引用三项天数的简单相加**。

## 四、拒绝计算的情形（设计上的，不是缺陷）

### 硬拒绝

```
if g >= WACC:
    拒绝计算，返回 ok=False
    警告："永续增长率不低于 WACC，终值公式不成立；请检查假设。"
```

Gordon 模型在 `g >= WACC` 时终值趋于无穷或为负，任何数值输出都没有意义。
**遇到这个警告不要绕过，回去改假设。**

### 软警告

`PT_terminal / EV > 0.75` 时警告：
"终值占企业价值超过 75%，结论对永续假设高度敏感，必须展示敏感性矩阵。"

用默认参数（5 年、g 3%、WACC 10%、收入增速 8%）跑，
终值占比通常在 **72%–76%**，即**默认参数几乎必然触发或逼近这条警告**。

**这不是 bug，是 DCF 的固有性质**：明确预测期越短，终值占比越高。
处理方式是把敏感性矩阵放进交付物，而不是把警告删掉。

降低终值占比的正当手段：延长 `years`、提高 `revenue_growth`、
提高 WACC 与 g 的差。**不要为了"好看"而调这些参数——它们每一个都要有依据。**

## 五、敏感性矩阵：DCF 必须输出

WACC × 永续增长率 二维矩阵，**每个单元格是按对应参数完整重算**，不是线性插值。

- 中心格应等于该情景的 `equity_value`（**可用来验证矩阵没算错**）。
- 默认 ±2 步：WACC 步长 1pp，g 步长 0.5pp，得到 5×5。

实测（基准情景，中心 10% / 3% = 1,575.7 亿，单位亿元）：

| g \ WACC | 8% | 9% | 10% | 11% | 12% |
| --- | --- | --- | --- | --- | --- |
| 2.0% | 1,898.5 | 1,627.8 | 1,425.1 | 1,267.6 | 1,141.7 |
| 2.5% | 2,035.9 | 1,724.0 | 1,495.4 | 1,320.7 | 1,183.0 |
| 3.0% | 2,200.9 | 1,836.1 | **1,575.7** | 1,380.5 | 1,228.9 |
| 3.5% | 2,402.6 | 1,968.6 | 1,668.3 | 1,448.3 | 1,280.2 |
| 4.0% | 2,654.6 | 2,127.6 | 1,776.4 | 1,525.7 | 1,337.8 |

**区间宽度 1,141.7 – 2,654.6 亿（约 2.3 倍）。**
这说明对成熟期假设敏感的公司，DCF 单点值几乎不可用——
**必须给区间并说明主要敏感方向**，不能只报一个数。

看**区间宽度**，不看单点。

## 六、假设校准与取值纪律

**每一个驱动变量要么来自已核验事实/指标，要么显式标注为假设并写明理由。**
说不出依据的假设，天然不可验证 —— 这是本选题最容易失分的地方。

### 6.1 引擎自动校准的变量（报告里逐项引用 `assumption_sources`）

| 驱动变量 | 校准公式 | 依据 |
| --- | --- | --- |
| `revenue_base` | 最新一期营业收入 | primary 级证据优先（主表原文 > 摘要页四舍五入值） |
| `revenue_growth` | 近 N 年复合增速与最新同比**取较低者**，封顶 20% | 不把单一年份的高增长外推为五年期假设 |
| `gross_margin` | (营业收入 − 营业成本) / 营业收入 | `gross_margin` 指标 |
| `opex_ratio` | (销售 + 管理 + 研发 + 税金及附加) / 营业收入 | **必须用真实费用科目** |
| `tax_rate` | 所得税费用 / 利润总额，夹在 [0, 50%] | 有效税率 |
| `da_to_revenue` | `depreciation_total` / 营业收入 | 折旧 + 使用权资产折旧 + 摊销 |
| `capex_to_revenue` | **abs(capex)** / 营业收入 | 港股列报为投资流出、带负号 |
| `receivable_days` / `inventory_days` / `payable_days` | 引擎已算好的周转天数 | 不重算 |
| `net_debt` | −`net_cash` = 有息负债 −（货币资金 + 长期银行存款） | 见第七节 |
| `non_operating_assets` | 按公平值计入损益的金融资产等 | 长期存款若已净掉不得再加 |
| `shares` | 归母净利润 / 基本每股收益 | E2 级近似，须标注 |

### 6.2 反推期间费用率是错的

旧实现用 `opex_ratio = gross_margin − net_margin` 反推，看起来"有约束"，
实际等价于 **`EBIT = revenue × net_margin`**，即把 EBIT 当成净利润。
EBIT 里已经扣过一次所得税，再乘 (1 − 税率) 就是**重复扣税**。

实测某公司因此把 EBIT 从 209.8 亿元压到 158.7 亿元，**低估 24%**。
→ 必须用真实费用科目。缺明细时引擎会降级并告警，见到告警要人工核对。

### 6.3 隐含 EBIT 自检

`calibration_checks.ebit_calibration` 把模型隐含的
`revenue × (毛利率 − 期间费用率)` 与报表口径的 `利润总额 + 财务费用` 直接对比，
差异超 15% 时告警。差异主要来自其他收益、投资收益、减值等项目未纳入期间费用率 ——
这是模型的已知简化，**写明比藏着好**。

### 6.4 WACC 与终值增长率：刻意不自动取

- **默认的 WACC 10% / g 3% 是行业中性值，不是这家公司的。**
  引擎不会自动取，这是刻意的：它们依赖行业与市场数据，自动填会制造
  "看起来很确定"的假象。
- 换值要用 `overrides`，并写清依据：
  - WACC：无风险利率、β、股权风险溢价、税后债务成本的来源。
  - 终值增长率：长期通胀目标 + 实际增长，**不得超过长期 GDP 增速**。
- 所有假设都要记录来源与依据，**可被质疑、可被替换**。
- `data_quality.from_default_assumptions` 里列出的变量，
  在报告里**必须标注为「假设」并写明理由**，不得混进「取自公司数据」那一类。

### 6.5 倍数自检与交叉验证

- **自检（永远可用）**：算 DCF 隐含的 EV/EBITDA 与 P/E。
  落在常识区间（EV/EBITDA 3–40 倍、P/E 5–60 倍）之外时先怀疑**输入错了**，
  而不是"公司特别便宜/贵"。
- **交叉验证（需提供可比倍数）**：在 `overrides` 里给 `comparable_ev_ebitda`
  与 `comparable_pe`，反推隐含权益价值与每股价值，与 DCF 并列。
  **可比倍数只能由使用者提供并说明可比组选取依据，禁止自行编造同业倍数。**

### 6.6 压力情景必须证明自己"有压力"

`stress_diagnostic` 给出压力情景相对基准情景的权益价值变动幅度。
差异不足 2% 时 `insufficient = true`，表示**本次压力测试没有构成实质压力**，
报告中必须写明，不得宣称"风险已充分量化"。

另有一个实测失效点：净现金公司（`net_debt` 为负）的债务风险规则
若以**净值**作规模基准，调整量会退化成 +0.03 元，三情景数值看起来一模一样。
规模基准必须用**有息负债总额**。

## 七、净债务桥接的五个坑

1. **长短借款明细与「計息借貸」总额不能相加**，否则重复计债。
   取值阶梯是**总括行优先、明细回退**：先取 `borrowings`，
   取不到才用 `short_term_debt` + `long_term_debt` + `bonds_payable`。
   估值侧不要自己再拼一遍，直接用 `financial_analysis` 已算好的
   `interest_bearing_debt` 指标 —— 它内含取值阶梯与**金额去重**
   （同一笔债务会在财务状况表与附注里各出现一次、fact_id 不同）。
   额外加一道对账：明细之和显著大于总括行时（如「計息銀行借貸」不含应付债券），
   改用明细并告警。

2. **租赁负债属于有息负债**，必须进净债务。港股/IFRS 报表下规模不小
   （实测某公司 1.03 亿元）。租赁负债同样有「合计」与「即期 + 非即期」
   两种粒度，不能相加。

3. **长期银行存款属于类现金**，要么在净债务里净掉、要么计入非经营性资产，
   **不能两头都算**（会重复计一次百亿元级别的资产）。
   实测某公司漏掉长期银行存款 110.88 亿元 + 租赁负债 1.03 亿元，
   净债务从 −177.73 亿元算成 −67.88 亿元，**权益价值等额低估 109.85 亿元**。

4. **非经营性资产必须加回权益价值**，否则估值系统性偏低。
   如按公平值计入损益的金融资产（`financial_assets_fvtpl`）不产生 FCFF，
   但属于股东的钱。

5. **少数股东权益要扣除**。用合并口径的 EV 减归母权益时，
   少数股东那部分不属于上市公司股东。

## 八、相对估值的口径纪律

- PE、EV/EBITDA、PB **只与业务模式和口径相近的同行比较**。
- 必须展示**同行选择规则、中位数、四分位区间和异常值剔除前后差异**。
- **口径矛盾不直接比较**：公司使用调整后利润、同行使用法定净利润时，
  显示口径差异，不要硬拉在一起排分位。
- 同行怎么选：先按行业与业务相似度筛，再按规模、地区和收入结构；
  **显示选择规则并允许剔除**。

## 九、输出纪律汇总

- 输出**区间，不输出目标价**。
- 不输出单点目标价，只输出按情景分布的价值区间——**避免变成荐股**。
- 每个估值结果附带明确的不确定性说明与适用边界。
- 三表不平、单位错位、口径未统一时，**先修数据再估值**。
- 用待核验数据跑出来的区间没有意义。
- **金融逻辑维度的一票否决项**：三表不平或因果倒置。
- **风险审慎维度的一票否决项**：收益保证或确定性荐股。
