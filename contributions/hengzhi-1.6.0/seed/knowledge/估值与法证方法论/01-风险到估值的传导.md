# 风险到估值的传导

竞赛方案最值钱的一句话是「**风险如何改变现金流和估值**」。
多数作品停在"算了一堆比率"，做不出"把回款天数拖到压力情景，DCF 区间实时下降"
这个闭环。本文件说明这条链条怎么接起来。

---

## 一、三情景的定义（方案原文）

| 情景 | 假设原则 | 用途 |
| --- | --- | --- |
| **基准** | 管理层计划中**可被历史与行业证据支持**的部分 | 最可能路径 |
| **乐观** | 需求、价格或良率改善，但**不得同时把所有参数调到最好** | 估值上界与催化剂 |
| **压力** | 将**最高优先级风险**映射到回款、毛利、减值或资本开支 | 损失承受与安全边际 |

**压力情景的参数必须由法证发现推导出来，不允许手填一个悲观数字了事。**
每一条参数改动都要能回答"是哪个 `rule_id` 让我这么改的"。

## 二、传导表（异常 → 模型参数 → 影响路径）

| 异常 | 模型参数 | 影响路径 |
| --- | --- | --- |
| 应收回款恶化 | `receivable_days` ↑ | 营运资本占用增加，FCFF 下降 |
| 毛利率解释不足 | `gross_margin` ↓ | EBIT 与终值下降 |
| 研发资本化上升 | `opex_ratio` ↑ | 当期利润下降，资本化资产摊销上升 |
| 存货积压 | `inventory_days` ↑ | 现金占用与减值损失增加 |
| 扩产计划激进 | `capex_to_revenue` ↑ | 近端 FCFF 下降，终值不确定性增加 |
| 盈利现金含量不足 | `wacc` ↑ / `terminal_growth` ↓ | 折现率风险溢价上调、终值增长率下调 |
| 扣非后主营盈利弱 | `sustainable_profit_discount` ↑ | 估值基数（扣非口径）下调 |
| 商誉减值 | `impairment_to_revenue` ↑ | 首年一次性税前损失，EV 与净资产同步下降 |
| 短债缺口 | `net_debt` ↑ | 净债务增加，EV 转权益价值下降 |
| 经营现金流恶化 | `near_term_fcff_haircut` ↑ | 近端两年 FCFF 折减 |
| 体外资金占用 | `sustainable_profit_discount` ↑ | 可分配给股东的利润低于账面 |
| 关键科目缺失 / 勾稽不成立 | `data_confidence` ↓ | **全部估值结果降级为参考值** |

完整 14 条映射与 `step`、`direction` 见估值压力测试技能包的
`references/valuation-contract.md`。

## 三、传导的幅度公式

```
weight = SEVERITY_WEIGHT[severity]      # critical 1.0 / high 0.7 / medium 0.4 / low 0.15
delta  = step × weight
```

- 比例类参数（`wacc` 0.10、`gross_margin` 0.60）：改动是**绝对百分点**。
- 天数类参数（`receivable_days` 45）：改动是**乘性的**（`delta × 45`）。

**实测参考**（收入基数 430 亿、基准 WACC 10%、g 3%）：

| 规则 | 严重度 | 参数改动 |
| --- | --- | --- |
| `R_AR_01` | high | 应收天数 45 → 51.3（+14%） |
| `R_CFO_01` | high | WACC 10.00% → 10.35%；g 3.00% → 2.65% |
| `R_MARGIN_01` | medium | 毛利率 60.0% → 59.2% |
| `R_GW_01` | medium | 首年减值 / 收入 0 → 1.2% |

四条规则叠加后，压力情景权益价值从 1,575.7 亿降到 1,387.6 亿（约 **−11.9%**）。

**这份参考说明单条规则的幅度是刻意保守的。**
如果交付物里压力情景只比基准低 1%–2%，说明**严重度被低估或规则命中偏少**，
要在报告里点出来，而不是宣称"风险对估值影响有限"。

## 四、三个参数旋钮的作用位置（决定影响大小）

| 旋钮 | 作用位置 | 影响范围 |
| --- | --- | --- |
| `impairment_to_revenue` | 首年 EBIT（税前一次性） | **仅第 1 年** FCFF |
| `near_term_fcff_haircut` | **前两年** FCFF | 第 1–2 年 |
| `sustainable_profit_discount` | **整条** FCFF 流（含推出终值的末年） | 全程 + 终值 |

所以同量级的 `sustainable_profit_discount` 对估值的影响**远大于**
`near_term_fcff_haircut`。这个差别解释了为什么 `R_NREC_01`（非经常性损益支撑利润）
的 `step` 是 0.10，而 `R_OCF_01` 的 `step` 也是 0.10 但效果弱得多。

`net_debt` 与 `non_operating_assets` 则是**在 EV → 权益价值的桥接处一次性扣除/加回**，
不影响 FCFF 本身。净债务取不到时保持 0，会让权益价值系统性偏高——必须在交付物写明。

## 五、未匹配的规则必须显式列出

两类情形都会进入 `unmatched_risks`：

1. `该规则未定义估值传导路径` —— 该 `rule_id` 不在传导表里。
2. `参数 X 缺失，无法传导` —— 映射的参数为 `None` 或不存在。

**两类都必须在交付物里列为"待补假设"，不能静默丢掉。**
否则压力情景看起来跑通了，其实漏了风险，报告会虚假地"稳健"。

`data_confidence` 是特例：它被显式跳过，表示"整体降级为参考值"，
不作为数值参数参与计算。

## 六、压力情景健康检查

拿到结果后逐项核对：

| 检查 | 期望 | 异常时的处置 |
| --- | --- | --- |
| `stress.equity_value < base.equity_value` | 成立 | 若 ≥ 基准，逐条读 `path` 找方向矛盾 |
| `risk_adjustments_stress` 里 `from != to` | 每项都成立 | `from == to` 表示该规则没真正改变参数，单独说明 |
| `unmatched_risks` 为空 | 理想 | 非空必须列为待补假设 |
| 传导项数 ≈ 命中规则数 | 大致相当 | 明显偏少说明映射覆盖不足 |
| 终值占比 | 记录并给出矩阵 | > 75% 必须展示敏感性矩阵 |

## 七、"风险联动估值"消融实验

方案的四个消融实验里，**估值联动消融**（风险与估值分离）是用来证明
"风险参数化使结论能影响决策"的。做法：

- **对照组**：只给三情景的假设表与估值区间，风险清单与估值互不关联。
- **实验组**：压力情景参数由法证发现自动推导，每条改动带 `rule_id` 来源。

要展示的是：**实验组的压力情景与基准情景有实质差异，且差异可归因到具体风险**；
对照组则只能靠人工拍一个悲观假设，说不出为什么。

## 八、裁决与约束

- 输出**区间，不输出目标价**。三情景权益价值是"按情景分布的合理价值区间"，
  不是目标价，也不构成投资建议。交付物必须保留这层免责表述。
- 每个关键数字都要能回答"参数从哪来"：历史值（哪一期）、同行值（哪几家的中位数）、
  还是规则推导（哪个 `rule_id`）。没有来源的就是假设，要显式标注为假设。
- **不修改原始事实、不覆盖既有运行结果。** 需要改假设就用 `overrides` 显式覆盖并留痕。
- 三表不平、单位错位、口径未统一时**先修数据再估值**。
  用待核验数据跑出来的区间没有意义，且会污染后续结论。
