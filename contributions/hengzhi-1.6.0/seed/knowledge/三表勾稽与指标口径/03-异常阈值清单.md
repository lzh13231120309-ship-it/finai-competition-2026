# 异常阈值清单

**阈值是经验值，不是监管标准。** 行业差异大的科目（毛利率、应收天数、存货周转）
必须先说明行业口径是否适用。银行、保险、证券**不能套用**一般工商企业的
流动比率与净负债判断（方案明确排除金融业）。

---

## 一、指标层启发式信号（`analyze_financial_report` 输出）

这些信号是**指标计算阶段的顺手提示**，比法证规则更宽松，用于快速定位可疑年份。

| 信号代码 | 触发条件 | 阈值 |
| --- | --- | --- |
| `weak_profit_cash_conversion` | 净利润 > 0 **且** `经营现金流 / 净利润 < 0.5` | 0.5 |
| `nonrecurring_profit_concentration` | `(归母净利润 − 扣非归母) / 归母净利润 > 0.3` | 30% |
| `receivables_growth_ahead_of_revenue` | `应收同比增速 − 收入同比增速 > 0.2` | 20 个百分点 |
| `inventory_growth_ahead_of_revenue` | `存货同比增速 − 收入同比增速 > 0.2` | 20 个百分点 |
| `loss` | 净利润 < 0 | — |
| `negative_operating_cash_flow` | 经营现金流 < 0 | — |

注意阈值差异：**指标层用 0.5，法证层用 0.8**（见下表 `R_CFO_01`）。
两层不是矛盾，是**筛选粒度不同**——指标层求宽、法证层求严。

## 二、十四类法证规则阈值速查

| rule_id | 类别 | 触发条件（实测实现） |
| --- | --- | --- |
| `R_AR_01` | 收入质量 | `应收同比增速 − 收入同比增速 > 20pp` |
| `R_INV_01` | 存货质量 | `存货同比增速 − 收入同比增速 > 20pp` |
| `R_CFO_01` | 利润现金匹配 | `净利润 > 0 且 经营现金流/净利润 < 0.8` |
| `R_MARGIN_01` | 毛利异常 | 毛利率同比变动**绝对值** `> 5pp` |
| `R_NREC_01` | 非经常项目 | `(归母净利润 − 扣非归母)/归母净利润 > 30%` |
| `R_GW_01` | 资产减值 | `商誉/归母净资产 > 30%` **且** 归母净利润同比下滑 |
| `R_DEBT_01` | 偿债与流动性 | `短期借款/货币资金 > 1`（仅时点组跑一次） |
| `R_SETTLE_01` | 收入质量 | `销售商品收到现金/营业收入 < 0.90` |
| `R_EXP_01` | 费用与资本化 | `(研发+销售+管理)/收入` 同比下降 `> 2pp` |
| `R_OCF_01` | 利润现金匹配 | 收入同比增长 **且** 经营现金流为负 |
| `R_CAP_01` | 投资与资本化 | `资本开支/收入` 同比升 `> 5pp` **或** `资本开支/折旧摊销 > 4 倍` |
| `R_RPT_01` | 关联方与资金占用 | `(其他应收款 + 预付款项)` 增速 `− 收入增速 > 30pp` |
| `R_DISC_01` | 披露质量 | 最新一期关键六项**缺失 ≥ 2 项**（见下） |
| `R_TIEOUT_01` | 会计一致性 | 勾稽恒等式失败（由 `diagnose_tieouts` 派生） |

### 三个需要额外说明的规则

**`R_CAP_01` 的两个独立信号**，命中任一即可：

1. `资本开支/收入` 同比上升 > 5pp —— 投资强度跳变。
2. `资本开支/折旧摊销 > 4 倍` —— 投资远超维持性支出。
   可能是真实扩张，也可能是**把费用包装成资产以平滑利润**。

注意：竞赛方案的附录 A 把 `R_CAP_01` 描述为"研发资本化上升并显著增厚利润"。
当前实现用的是**资本开支强度**这个更可复算的代理信号（研发资本化率需要
`开发支出 / 研发费用` 两个附注科目，数据可得性差）。**这是代理信号而非同一命题**，
报告中要如实说明；若材料能取到研发资本化率，应补充该信号。

**`R_RPT_01` 是代理信号，不是结论。**
年报正文不总是把"关联方资金占用"做成可直接取数的科目，它通常散在附注的往来款明细里。
但「其他应收款 + 预付款项」合计增速远快于收入、且在总资产里占可观比重，
是资金体外循环的典型**外观**——方向明确、可复算，因此作为**筛查起点**。
必须回附注查前五大对象是否与控股股东或关联方相关。

**`R_DISC_01` 有三个必须的限定，否则大面积误报**：

1. **只看最新一期**。历史年份常只出现在五年摘要里，摘要按定义只列少数几行；
   拿它去要求完整的六项关键科目，等于把"这是摘要"判成"披露不完整"。
2. **要求该组里至少有一条主表来源（`source_tier = primary`）的事实**。
   整组都来自摘要页时，缺失是排版体例，不是披露缺陷。
3. **有合并口径数据时，只在合并口径上判定**。母公司单体报表按披露惯例
   只列"本公司財務狀況表"，本就没有营业收入/净利润/经营现金流，
   拿合并口径的六项去要求它必然误报 ——
   实测曾让 `R_DISC_01` 成为排名第一的发现，纯属体例问题。

关键六项：`revenue`、`net_profit`、`operating_cash_flow`（区间值）；
`assets`、`liabilities`、`equity`（时点值）。

### 二之二、检查规则输入前必须先确认"这不是变动额"

现金流量表的「營運資金變動」区重复使用资产负债表科目名，但给的是**本期变动量**。
若它混进余额类输入，会同时污染两侧：既凭空多出一个"余额"，
又把真实余额拖入 `duplicate_conflict` 一起降级。
所有以 `BALANCE_CODES` 科目为输入的规则都要先确认该事实不是变动行
（护栏细节见「会计口径与数据陷阱/03-港式H股与英文报表识别.md」第十节）。

同理，现金流量表「調整項」区把折旧拆成
「物業、廠房及設備折舊」与「使用權資產折舊」两行时，必须分开登记为
`depreciation` 与 `depreciation_rou_assets`；合并成同一个代码会互相判冲突、
双双失效。判断一个重复科目是"冲突"还是"明细拆分"，是使用任何余额/流量类
规则之前的必要一步。

## 三、评分与严重度分档

```
risk_score = 0.30×magnitude + 0.25×persistence + 0.20×peer_extremeness
           + 0.15×cash_impact + 0.10×disclosure_uncertainty
```

| 因子 | 取值方式 |
| --- | --- |
| `magnitude` | `|观测值 − 阈值| / span × 100`，偏离阈值一个 `span` 记满分 100，上限 100 |
| `persistence` | `连续命中期数 / 3 × 100`，上限 100（最多回溯 3 年，逐年真实命中才算） |
| `peer_extremeness` | `|观测 − 同行中位数| / |中位数| × 100`；**无同行数据取中性 50 并标记 `peer_data_missing`** |
| `cash_impact` | 该规则在 `CASH_IMPACT_RULES` 里记 100，否则记 40 |
| `disclosure_uncertainty` | 依赖事实中"无证据编号"记 1.0、"置信度 < 0.9"额外记 0.5，除以依赖数 × 100；无依赖记 100 |

`cash_impact = 100` 的规则（真正影响现金流或净资产的）：
`R_AR_01`、`R_INV_01`、`R_CFO_01`、`R_SETTLE_01`、`R_OCF_01`、`R_DEBT_01`、
`R_CAP_01`、`R_RPT_01`。

### severity 分档（由 risk_score 推出，不是人工填的）

| 分数区间 | severity |
| --- | --- |
| ≥ 75 | `critical` |
| ≥ 55 | `high` |
| ≥ 35 | `medium` |
| < 35 | `low` |

`R_TIEOUT_01` 不走五因子：`resolution = unit_misplacement` 记固定 **90.0**（critical），
其他可诊断情形记 **65.0**（high）。`not_unit_issue` 的失败不生成发现。

### severity 直接决定估值幅度

压力情景的参数改动 = `step × SEVERITY_WEIGHT[severity]`，
其中 critical 1.0 / high 0.7 / medium 0.4 / low 0.15。
**所以 severity 标错会直接改变估值结论**——这要求严重度逐条复核。

## 四、发现合并规则

同一 `rule_id` + 同一公司 + 同一口径，**跨年命中合并成一条**：

- `periods` 列出所有命中年份（倒序）。
- `consecutive_periods` 取最大连续期数。
- `severity` / `risk_score` / `detail` / `observed` / `threshold` 取**分数最高那一期**。

不合并的话 Top 10 会被同一规则的三个年份挤满，排序失去信息量。

## 五、竞赛方案的「十类异常指标模块」对照

方案第六条列了十个模块，与本项目实现的映射关系：

| 方案模块 | 本项目规则 |
| --- | --- |
| 利润现金匹配（CFO/净利润、应计利润） | `R_CFO_01`、`R_OCF_01` |
| 收入质量（应收增速−收入增速、回款天数） | `R_AR_01`、`R_SETTLE_01` |
| 存货质量（存货增速−收入增速、周转天数、跌价覆盖） | `R_INV_01` |
| 毛利异常（同比、环比、同行偏离、量价桥） | `R_MARGIN_01` |
| 费用与资本化（研发资本化率、费用率变动） | `R_EXP_01` + `R_CAP_01`（代理） |
| 资产减值（商誉/净资产、账龄结构） | `R_GW_01` |
| 非经常项目（扣非差异、补助/利润） | `R_NREC_01` |
| 关联与集中度（关联销售占比、前五客户/供应商） | `R_RPT_01`（代理） |
| 偿债与流动性（净债务/EBITDA、短债现金比） | `R_DEBT_01` + `current_ratio`/`quick_ratio`/`cash_ratio` |
| 营运资金效率（存货/应收/应付天数、现金循环周期） | `inventory_days`、`receivables_days`、`payables_days`、`cash_conversion_cycle` |
| 会计一致性（资产=负债+权益、现金勾稽、口径） | `R_TIEOUT_01` + 全部 10 条勾稽恒等式 |

未实现、需要在报告中说明为"未覆盖范围"的部分：
**应计利润（(净利润−CFO)/平均总资产）同行分位**、**账龄结构**、
**客户与供应商集中度**、**研发资本化率**、**合同资产/收入**、
**跌价准备覆盖率**、**利息保障倍数**、**净债务/EBITDA**。
这些都需要附注明细，扫描版年报的可得性差。

## 六、使用纪律

- 规则是**启发式筛查**，不是监管标准，**不构成造假认定**。
  交付物里用"待核验事项""需要解释的差异"，不要用"造假""舞弊"。
- 阈值是经验值。行业差异很大的科目先说清行业口径是否适用。
- **允许并鼓励"未发现异常"的结论。** 不要为了填满报告而降低阈值或重复计数。
- 每条发现都必须带 `counter_checks`（反证检索方向）与 `open_questions`（未解问题），
  且**必须真的去查**——包括"查了、但没找到解释"这种结果。
- Top-5 应覆盖人工确认的重要异常不低于 80%；误报率是评测项。
