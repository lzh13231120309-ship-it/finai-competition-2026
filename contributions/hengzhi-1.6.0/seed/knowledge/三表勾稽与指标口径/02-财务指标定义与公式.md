# 财务指标定义与公式（实际实现）

所有指标都由**确定性代码**用 `Decimal` 计算，LLM 不参与数值计算。
比例统一为分数（`0.2` = 20%），百分比只在展示层格式化。

---

## 一、时点值指标（资产负债表）

| 指标代码 | 公式 | 备注 |
| --- | --- | --- |
| `debt_ratio` | `liabilities / assets` | 资产负债率 |
| `current_ratio` | `current_assets / current_liabilities` | 流动比率 |
| `quick_ratio` | `(current_assets − inventory) / current_liabilities` | 速动比率，口径写在公式里 |
| `cash_ratio` | `cash / current_liabilities` | 现金比率 |

## 二、区间值指标（利润表，分母为 revenue）

| 指标代码 | 公式 | 备注 |
| --- | --- | --- |
| `gross_margin` | `(revenue − cost_of_revenue) / revenue` | 无营业成本时回退 `gross_profit / revenue`（IFRS 常见） |
| `net_margin` | `net_profit / revenue` | — |
| `operating_margin` | `operating_profit / revenue` | — |
| `operating_cash_margin` | `operating_cash_flow / revenue` | 收入现金转化 |
| `cash_conversion` | `operating_cash_flow / net_profit` | **盈利现金含量**，法证核心指标 |
| `nonrecurring_profit_share` | `(parent_net_profit − nonrecurring_adj_parent_profit) / parent_net_profit` | **扣非前后归母利润差额占比** |
| `free_cash_flow` | `operating_cash_flow − capex` | 口径是 OCF−Capex，非 FCFF |

## 三、周转与回报（分子区间值 ÷ 分母平均时点值）

**关键口径**：周转率与 ROE/ROA 的分子是**区间值**、分母是**时点值**，
所以分母必须用**期初期末平均**：

```
平均余额 = (期末余额 + 期初余额) / 2        # 期初 = 上年 12-31
```

不要用期末单点做分母 —— 期末资产规模通常大于年初，会系统性偏高。

| 指标代码 | 公式 | 备注 |
| --- | --- | --- |
| `roe` | `parent_net_profit / 平均 parent_equity` | 归母 ROE |
| `roe_total` | `net_profit / 平均 equity` | 含少数股东 |
| `roa` | `net_profit / 平均 assets` | 总资产报酬率 |
| `inventory_turnover` | `cost_of_revenue / 平均 inventory` | 存货周转率（次数） |
| `receivables_turnover` | `revenue / 平均 receivables` | 应收周转率（次数） |
| `payables_turnover` | `cost_of_revenue / 平均 payables` | 应付周转率（次数） |
| `asset_turnover` | `revenue / 平均 assets` | 总资产周转率 |
| `inventory_days` | `期间天数 × 平均 inventory / cost_of_revenue` | 存货周转天数 |
| `receivables_days` | `期间天数 × 平均 receivables / revenue` | **应收周转天数**，估值直接消费 |
| `payables_days` | `期间天数 × 平均 payables / cost_of_revenue` | 应付周转天数 |
| `cash_conversion_cycle` | `inventory_days + receivables_days − payables_days` | 现金循环周期（天） |

**应付周转的分子用营业成本**：采购额在多数年报里不直接披露，营业成本是行业惯例的
代理口径。公式字符串里写明用的是哪个分子，评审可以据此判断该代理是否适用于这家公司。

**现金循环周期只在三项天数同期齐备时才出数**。缺任何一项就不出这个指标 ——
用别期的天数凑一个合计，会得到一个看起来专业但没有意义的数字。

**不做年化**：报告期不足一年时（半年报 / 季报），周转类指标**不年化**，
公式里明确标注 `period basis, not annualized`，并把"期间天数"写进公式字符串。
期间天数 = `期末日 − 期初日 + 1`。

## 四、同比（YoY）

对以下科目计算同比：`revenue`、`net_profit`、`parent_net_profit`、
`nonrecurring_adj_parent_profit`、`operating_cash_flow`、`assets`、
`receivables`、`inventory`。

公式：`(current − prior_year) / prior_year`

**护栏**：上年基数为零或负数时，**不报告同比百分比**，改为提示
"上年基数为零或负数，不报告常规同比百分比；请比较绝对增减额"。
（负基数算出的"增长率"会反向，直接误导读者的方向判断。）

## 五、时间点值 vs 区间值的作用域

| 类型 | 科目示例 | 期间标签含义 |
| --- | --- | --- |
| instant（时点） | `assets`、`liabilities`、`equity`、`parent_equity`、`minority_equity`、`cash`、`receivables`、`inventory`、`current_assets`、`noncurrent_assets`、`current_liabilities`、`noncurrent_liabilities` | 某一天 |
| duration（区间） | `revenue`、`cost_of_revenue`、`gross_profit`、`net_profit`、`parent_net_profit`、`operating_profit`、`profit_before_tax`、`income_tax`、`operating_cash_flow`、`investing_cash_flow`、`financing_cash_flow`、`capex`、`depreciation`、`amortization` | 某一段 |

**跨表指标必须成对使用同类型数据**。混用是静默错误的常见来源。

## 六、指标异常判定（用来自检，不是业务结论）

自检脚本对指标做两层检查，**判据拆开**才不会误报：

- **有界比率**（`BOUNDED_METRICS`），正常应落在 `[-1, 1]`：
  `gross_margin`、`net_margin`、`operating_margin`、`operating_cash_margin`、
  `debt_ratio`、`nonrecurring_profit_share`、各类 `_yoy` 等。
  超出 `[-1, 1]` 就是异常数值 → 优先怀疑单位。
- **量级指标**（`LEVEL_METRICS`），用绝对荒谬阈值（如 > 100）：
  `roa`、`asset_turnover`、`roe`、`roe_total`、周转率、天数、`current_ratio`、
  `quick_ratio`、`cash_ratio`、`cash_conversion`。

**不能把 `current_ratio = 2.2` 当异常** —— 它落在 `[-1,1]` 之外但完全正常。
早期版本用统一判据，把正常流动比率全打成异常，噪声淹没真实信号。
