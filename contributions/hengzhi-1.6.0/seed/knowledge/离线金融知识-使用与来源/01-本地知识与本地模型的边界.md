# 本地知识与本地模型的边界

标题：本地知识与本地模型的边界
任务域：跨任务离线准备与来源管理
关键词：离线运行 本地模型 局域网 DeepSeek Ollama
适用范围：本项目工作流；具体会计与法律规定以对应来源版本为准
核验日期：2026-10-11
来源：https://docs.ollama.com/faq
资料性质：原创工程说明；官方链接仅支持对应格式或部署规范

知识库、文档解析、指标与估值的确定性计算可以使用本地文件和程序。聊天推理模型则是另一个依赖：云端 DeepSeek API 不会因为有了本地知识库就自动脱网运行。现场只有局域网时，要准备可访问的局域网推理服务或提前下载并验收本地模型。模型名称不是模型权重，配置中写一个名称不表示模型已经安装。

准备清单包括模型权重、分词器、量化格式、推理运行时、可用内存、上下文窗口和工具调用格式。选择模型要用实际材料验证财务数字、中文科目与工具调用，不能只看通用排行榜。先用脱网环境启动一次，再进行财报分析、估值与报告核验全链演练。知识检索成功只证明检索层离线可用；云端接口未断开不能叫全流程断网验收。

本项目提供 Ollama/OpenAI兼容入口，但使用者应确认服务实际存在。局域网地址与服务端口要由主办方或管理员确认，不能猜测接口。接口密钥、用户私有材料不写入知识条目。提前打包所有依赖与字体、OCR可执行文件、样本数据和参数快照。

官方Ollama FAQ说明本地运行和绑定配置；本条其余准备流程是项目工程建议。局域网并不天然保证没有外网，原赛事通知的封闭/半封闭环境要求也不能替代现场部署细则。
