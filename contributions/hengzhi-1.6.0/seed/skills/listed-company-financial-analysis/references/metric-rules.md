# 指标及核验规则

本参考定义财务判断的约束，不代表核心工具已实现每一指标。只交付已有可验证输入支持的指标，明确哪些由工具计算、哪些是此次补算。

## 可比性优先于指标数量

可比较数据必须匹配公司、报表范围、币种、单位、区间长度、会计口径及重述状态。余额和流量分开：期末应收不能当全年平均应收。半年数不能直接与全年数比较后称同比。

- 同比用对应上年同区间；环比用相邻、同长度的区间。若前期为正，可用 `(本期 - 前期) / 前期`。
- 前期为零时同比无法按普通公式计算；前期为负时优先写增亏、减亏或扭亏及绝对差额，不用普通增长百分比制造正负误导。若用户明确要求其他算法，明示其定义和局限。
- 单季发生额仅在累计期间连续、范围与口径一致、数据可靠时由相邻累计数相减。第二季可用半年减一季，第三季用前三季减半年，第四季用全年减前三季。比较季也必须同法推导；保留两端的证据。资产负债表时点余额不能这样相减后称单季金额。
- 追溯调整以可确认的最新比较口径为优先，保留调整前来源与版本；跨报告混用需解释。

## 常用指标

下表中的利润、收入、费用与现金流须属于同一区间，余额须属于同一时点；比率分母缺失或为零时不计算。

| 指标 | 公式/口径 | 边界 |
|---|---|---|
| 毛利率 | `(营业收入 - 营业成本) / 营业收入` | 收入应为正；银行/保险科目结构通常不适用 |
| 净利率 | 净利润 / 营业收入 | 归母净利润可另算归母净利率，不能替代后不改标签 |
| ROE（简化） | 归母净利润 / 平均归母权益 | 平均取期初期末；不能称披露的加权平均 ROE；平均权益非正时异常 |
| ROA（简化） | 净利润 / 平均资产 | 期初缺失不能用期末代替后称平均；半年/季度标明未年化 |
| 资产负债率 | 总负债 / 总资产 | 总负债不同于有息债务；金融企业的行业解释不同 |
| 流动比率 | 流动资产 / 流动负债 | 金融企业报表可能未分流动/非流动；无该分类则不适用 |
| 速动比率（简化） | `(流动资产 - 存货) / 流动负债` | 预付款等可能仍不可迅速变现；标明这是简化口径 |
| 现金流利润比 | 经营活动现金净流量 / 净利润 | 净利润为正才有常规解释；用归母分母须另标口径 |
| 应收周转 | 营业收入 / 平均应收账款 | 票据/融资项是否计入需说明；用净额还是原值需一致 |
| 存货周转 | 营业成本 / 平均存货 | 缺成本/期初值时不算；不可用收入替代成本 |
| 周转天数 | 区间实际天数 / 对应区间周转次数 | 不把半年指标机械乘 365；负/零分母不适用 |
| 净债务（指定口径） | 明确纳入的有息债务 - 明确可抵减的现金 | 缺债务/现金附注时不把总负债与货币资金代入 |
| 利息保障 | 明确口径 EBIT / 对应利息费用 | 利息费用不同于净财务费用；没有操作数不估算 |
| 自由现金流（简化） | 经营现金净流量 - 购建长期资产支付的现金 | CAPEX 口径需明示，不能减全部投资活动现金流 |

费用率使用相应费用/营业收入并明确费用类型。研发费用与资本化研发投入不是同一项。EBITDA 需要折旧、摊销等真实数据，不能从净利润简单加回净财务费用就称 EBITDA。

## 三表勾稽及差异分类

1. **资产负债表**：同范围、同日、同单位核对 `资产 = 负债 + 所有者权益`。归母权益不能代替全部权益；舍入误差的容忍度随展示单位/精度调整。
2. **利润表**：只在拥有完整构成科目时复核利润桥。不能忽略减值、其他收益、投资收益、所得税、少数股东损益等后称不平。
3. **现金流量表**：按报表明确列示核对三类活动净流量加汇率影响等调整与现金净增加额；再核对期初、净增加额和期末现金及现金等价物。
4. **跨表现金**：资产负债表“货币资金”不必等于现金流量表“期末现金及现金等价物”。检查受限资金、非现金等价物存款等附注。缺调节表只能标“待解释差异”，不能直接判错。

差异输出需包括两侧科目/公式、期间、范围、单位、绝对差额、适用容差、来源和可能原因。工具固定容差若不适合文档展示精度，说明限制，不替工具默改数据。

## 异常信号应如何表述

“净利润为正而经营现金流为负”是可复核现象；“可能受应收增长或季节性影响”是需验证假设；“财务造假”不能由这两者推出。中标金额不是已确认收入，质押不等于违约，负经营现金流也不单独证明偿债困难。

每条信号给出触发事实与期间、比较基准、证据、未排除解释及下一步核查资料。启发式阈值应显示其定义，避免称行业通用标准、监管红线或已验证风险概率。审计意见、持续经营事项、诉讼和关联方事项只能在原文披露时引用；未检索到不能写“无风险”。
