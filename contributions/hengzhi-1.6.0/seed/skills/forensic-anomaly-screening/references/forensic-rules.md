# 法证规则库（14 条）

引擎实现于 `server/forensics.py`：`RULE_META`（名称/分类）、`VALUATION_LINKS`（估值传导）、`COUNTER_GUIDANCE`（反证方向）、`OPEN_QUESTIONS`（未解问题）、`CASH_IMPACT_RULES`（现金流权重）、`ForensicEngine.RULES`（判定逻辑）。

**阈值与实现的唯一真源是代码**；本文件与代码不一致时以代码为准。每条给出：触发条件、需要什么证据、反证方向、估值传导。

---

## R_AR_01 应收增速持续快于收入

- **触发**：应收账款同比增速 − 营业收入同比增速 > **20 个百分点**。
- **含义**：收入确认节奏快于回款。可能是放宽信用政策（正常竞争手段），也可能是把货压给渠道提前确认收入。
- **需要补充的证据**：应收账龄结构、坏账准备计提比例变化、主要客户集中度、附注里的信用政策表述。
- **反证方向**：大客户改变结算方式（票转账）、并购并表带来应收、季节性结算集中在下一期。
- **估值传导**：应收天数上升 → 营运资本占用增加 → FCFF 下降（`receivable_days` ↑）。计入现金流权重。

## R_INV_01 存货增速背离收入

- **触发**：存货同比增速 − 营业收入同比增速 > **20 个百分点**。
- **含义**：备货超前于销售。可能是为新品或原料涨价备货，也可能是产品滞销。
- **需要补充的证据**：存货结构（原材料/在产/成品）拆分、跌价准备计提比例、期后销售与在手订单。
- **反证方向**：原料涨价前的策略性囤货、新产线投产备料、合并范围变化。
- **估值传导**：存货天数上升 + 跌价率 → 现金占用与减值损失增加（`inventory_days` ↑）。计入现金流权重。

## R_CFO_01 利润现金含量不足

- **触发**：净利润 > 0 且 经营活动现金流净额 / 净利润 < **0.80**。
- **含义**：账面盈利没有对应的现金流入。
- **需要补充的证据**：现金流量表补充资料、收现比、应付账款是否被异常拉长。
- **反证方向**：高增长期营运资本主动扩张、票据结算周期长、季节性错配。
- **估值传导**：风险溢价上调 WACC、终值增长率下调（`wacc` ↑、`terminal_growth` ↓）。计入现金流权重。

## R_MARGIN_01 毛利率同比大幅变动

- **触发**：毛利率同比变动绝对值 > **5 个百分点**。
- **含义**：缺少可验证解释的毛利跳变。
- **需要补充的证据**：收入与成本的量价拆分、产品结构、单位成本、会计政策（如运费归类）。
- **反证方向**：产品结构高端化、原料价格传导、产能利用率变化、成本归集口径变更。
- **估值传导**：毛利率向同行回归 → EBIT 与终值下降（`gross_margin` ↓）。

## R_NREC_01 非经常性损益支撑利润

- **触发**：(归母净利润 − 扣非归母净利润) / 归母净利润 > **30%**。
- **含义**：利润主要来自一次性来源，可持续性存疑。
- **需要补充的证据**：非经常性损益明细（政府补助、处置收益、公允价值变动）、是否连续多年出现同类项目。
- **反证方向**：产业政策补贴具备可持续性、资产处置有明确商业理由。
- **估值传导**：扣非口径下调可持续利润 → 整条 FCFF 流折让（`sustainable_profit_discount` ↑）。

## R_GW_01 商誉风险

- **触发**：商誉 / 归母净资产 > **30%** 且归母净利润同比下滑。
- **含义**：减值测试关键假设不透明，减值往往滞后确认。
- **需要补充的证据**：商誉所在资产组的可收回金额测算、关键假设与敏感性、业绩承诺完成情况。
- **反证方向**：被并购方经营超预期、减值测试假设充分保守。
- **估值传导**：商誉减值 → 首年一次性税前损失 → EV 与净资产同步下降（`impairment_to_revenue` ↑）。

## R_DEBT_01 短期债务超过货币资金

- **触发**：短期有息负债 − 货币资金 > 0。
- **含义**：短期偿付缺口需要用经营现金流或再融资填补。
- **需要补充的证据**：有息负债到期结构、授信额度与实际使用、担保与抵质押、表外负债（明股实债、回购义务）。
- **反证方向**：授信充足且为低成本备用额度、集团内资金调剂、季节性高峰。
- **估值传导**：短债缺口 → 净债务增加 → EV 转权益价值下降（`net_debt` ↑）。计入现金流权重。

## R_SETTLE_01 收现比偏低

- **触发**：销售商品、提供劳务收到的现金 / 营业收入 < **0.90**。
- **含义**：收入现金回笼效率下降；与 R_AR_01 视角不同（一个看余额，一个看流量）。
- **需要补充的证据**：票据结算比例与票据种类（银承/商承）、预收与合同负债变化。
- **反证方向**：以银行承兑汇票为主且票据信用良好、预收模式转变。
- **估值传导**：营运资本占用 → FCFF 下降（`receivable_days` ↑）。计入现金流权重。

## R_EXP_01 期间费用率异常下降

- **触发**：（研发 + 销售 + 管理）费用率同比下降超过 **2 个百分点**。
- **含义**：费用率无故下降可能是费用被资本化/递延，或计提不足。
- **需要补充的证据**：费用明细、研发支出资本化率、长期待摊费用、股份支付、人力成本。
- **反证方向**：规模效应真实显现、组织优化、一次性费用基数高导致同比失真。
- **估值传导**：期间费用率上调 → EBIT 与终值下降（`opex_ratio` ↑）。

## R_OCF_01 收入增长但经营现金流为负

- **触发**：营业收入同比为正，且经营活动现金流净额 < 0。
- **含义**：经营本身失血，依赖融资维持。
- **需要补充的证据**：现金流量表结构、营运资本变动明细、是否靠拖延付款改善表观现金流。
- **反证方向**：扩张期铺底营运资金、结算节点错配、大宗商品价格波动造成的占用。
- **估值传导**：近端两年 FCFF 折减（`near_term_fcff_haircut` ↑）。计入现金流权重。

## R_CAP_01 资本开支强度异常上升

- **触发**（任一）：资本开支 / 营业收入 同比上升 > **5 个百分点**；或 资本开支 / 折旧摊销 > **4 倍**。
- **含义**：投资强度跳变。可能是真实扩张，也可能是把费用包装成资产以平滑利润。
- **需要补充的证据**：资本开支投向与在建工程进度、研发支出资本化比例、募投项目承诺。
- **反证方向**：行业景气周期中的扩张期、在建工程集中转固、并购整合带来的资产重估。
- **估值传导**：资本开支 / 收入上升 → FCFF 分子减少（`capex_to_revenue` ↑）。计入现金流权重。

## R_RPT_01 其他应收款与预付款项异常膨胀（关联方资金占用的代理信号）

- **触发**：（其他应收款 + 预付款项）同比增速 − 营业收入同比增速 > **30 个百分点**。
- **为什么是代理信号**：年报正文不总是把「关联方资金占用」做成可直接取数的科目，它通常散在附注的往来款明细里。而这两项合计增速远快于收入、且在总资产里占到可观比重，是资金体外循环的典型外观——方向明确、可复算，因此作为**筛查起点而不是结论**。
- **需要补充的证据**：其他应收款前五大对象是否与控股股东/关联方相关、预付款项对应供应商的关联关系、是否有非经营性资金占用的决议与还款安排。
- **反证方向**：集团内正常资金池调剂且已披露、历史往来款已按期偿还、预付款对应真实的大宗采购锁价条约。
- **估值传导**：体外资金占用 → 可分配利润低于账面 → 估值基数折让（`sustainable_profit_discount` ↑）。计入现金流权重。

## R_DISC_01 最新一期关键科目披露不完整

- **触发**：最新一期的关键六项（营业收入、净利润、经营活动现金流净额、资产总额、负债总额、权益总额）中缺失 **≥ 2 项**。
- **含义**：这不是"公司做了什么"，而是"这份材料够不够支撑分析"。缺项越多，下游指标与勾稽的可验证性越低，必须显式降级而不是沉默地算下去。
- **两个必要限定**（否则大面积误报）：只看最新一期（历史年份常只出现在五年摘要里，摘要按定义只列少数几行）；且该组里至少有一条主表来源的事实（整组都来自摘要页时，缺项是排版体例，不是披露缺陷）。
- **需要补充的证据**：缺失科目能否在附注中补全、该报告是否只是摘要版、缺失是否导致关键勾稽无法验证。
- **估值传导**：不直接改数值；标记数据可信度（`data_confidence`），估值结果降级为参考值。

## R_TIEOUT_01 会计勾稽不成立

- **触发**：任一恒等式（见知识库《三表勾稽恒等式》）差额超出舍入容差。
- **处理方式**：引擎做单变量数量级替换搜索，给出 `resolution`：
  - `unit_misplacement`：只需把某个科目乘/除 10 的整数次幂即可配平，`fix.scale_shift` 给出建议指数。
  - `ambiguous`：多个单变量方案都能配平，必须转人工。
  - `not_unit_issue`：单纯的数量级调整救不回来，可能涉及漏项、口径混用或真实错误。
  - `undetermined`：信息不足。
- **红线**：**绝不自动改数**。任何调整都必须由人确认，并在报告里保留原始值与调整依据。
- **估值传导**：数据可信度不足 → 全部估值结果降级为参考值。

## 评分与严重度

`risk_score = 0.30×magnitude + 0.25×persistence + 0.20×peer_extremeness + 0.15×cash_impact + 0.10×disclosure_uncertainty`

| 因子 | 取值 | 说明 |
| --- | --- | --- |
| magnitude | 0–100 | 超出阈值的幅度，按各自的 span 归一 |
| persistence | 0–100 | 连续命中期数 / 3 × 100，单期异动天然低分 |
| peer_extremeness | 0–100 | 有同行分位时按分位算；缺失取中性 50 并标记 `peer_data_missing` |
| cash_impact | 100 / 40 | 命中 `CASH_IMPACT_RULES` 记 100，其余 40 |
| disclosure_uncertainty | 0–100 | 依赖事实缺证据编号或置信度不足的比例；无依赖时记 100 |

严重度：`≥70` critical，`≥50` high，`≥35` medium，其余 low。

同一规则在同一公司同一口径上跨年命中会合并为一条，`periods` 列出所有命中年份，`consecutive_periods` 记连续期数，取风险分最高的期作为代表描述。
