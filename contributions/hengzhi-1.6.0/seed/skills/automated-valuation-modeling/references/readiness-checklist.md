# 数据就绪与交付检查

检索日期：2026-10-10。以下是本项目的原创建模检查项，不是来源资料对某家公司的结论。

## 建模前

- [ ] 公司身份唯一；不同公司的事实不混用；财务运行与法证运行对应。
- [ ] 基期及同比口径一致，期间流量不与期末存量混为一项；累计季度转换留有推导。
- [ ] 原币种、金额单位、财报合并范围及 OCR 歧义已复核。
- [ ] EBIT 与净利润有清楚桥接；利息、非经营收益、少数股东与税项不混入经营利润。
- [ ] Capex 用正支出额，D&A 是非现金费用加回；ΔNWC 表示占用增量，不能重复扣除基期余额。
- [ ] 应收天数以收入为分母，存货/应付天数以成本为分母；折算收入口径时保留成本率。
- [ ] 净债务、受限现金、租赁、少数股东、非经营资产和股数逐项检查；未知不自动当零。
- [ ] 每项市场数值有 `as_of/source/currency/method`；报价与股数对应同一日期和股票类别。
- [ ] 银行/保险/证券没有误用普通企业流动资金或净债务逻辑；核心资本约束缺失时不声称模型完整。

## 模型后

- [ ] 每个历史输入可定位公司证据；市场观察与假设在来源表分列。
- [ ] 渐变末年与稳态下一年增长、利润率、ROIC、再投资协调；终值没有直接延用异常末年 Capex。
- [ ] 折现因子适配各年折现率；终值位于预测末年，不多折现或少折现一年。
- [ ] Gordon 终值增长低于相应折现率；终值占比和敏感性均展示。
- [ ] 可比样本能重算倍数，日期/期间/币种一致；负分母、缺失来源和口径冲突有排除理由。
- [ ] 反向模型只解一个变量，有参数边界、残差与无解诊断。
- [ ] 模拟 seed、分布、相关性、样本规模、失败样本及分位数可复现；没有包装成胜率。
- [ ] 法证压力来源与参数传导一一对应；未映射风险和重复作用风险明确展示。
- [ ] 工作簿可打开、可编辑，关键公式能复算；若未重算缓存，明确写出。
- [ ] 交付的运行 ID、输入版本、导出路径真实存在；缺模块按实际状态披露。
