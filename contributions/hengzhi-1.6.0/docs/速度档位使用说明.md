# 回复速度档位（1.5.2）

聊天顶部模型选择器旁、设置→通用，均可选择并自动保存，下条消息生效。当前正在运行的一轮保持启动时的档位；如需立即换档，先停止后再发送问题。

| 档位 | 官方 DeepSeek 推理强度 | 用途 |
| --- | --- | --- |
| 快速 | low，保留思考 | 简单追问、概念解释、单项取数 |
| 均衡（默认） | high | 日常财报分析和一般核查 |
| 深度 | max | 复杂估值、跨期矛盾、研报审查 |

所有档位保留同样的工具、金融计算与核验要求、最大执行步数及输出额度。速度不等于确定的秒数，复杂任务选择快速可能降低推理充分程度；重大研究结论建议深度复核。

仅当接口域名为官方 api.deepseek.com 且模型为 deepseek-flash / deepseek-v4-flash / deepseek-v4-pro 时发送原生 thinking 与 reasoning_effort 参数。其他模型仅使用执行策略与回答范围提示，界面状态会说明未验证原生调速，不能保证相同加速效果。不自动切换模型。

DeepSeek 工具调用之间及后续对话会按官方协议回传保存在本机的 reasoning_content。旧消息缺失的推理字段为空，不虚构推理。上下文压缩仍按完整工具调用组处理，原记录保留在数据库。

官方参数依据（核对日期2026-10-15）：https://api-docs.deepseek.com/guides/thinking_mode/

验收记录：verification-packaged-speed-modes.json。它验证安装包实际发出三种不同强度、保留工具与推理协议，不代表真实云端延迟或财务准确率对比。
