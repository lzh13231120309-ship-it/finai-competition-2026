# 自动估值建模（1.2.0）

在任务里上传财报，先进行财报核验，然后点击输入框旁的「自动估值建模」。也可以直接对 Agent 说：

> 对这家上市公司做自动估值建模。复用已核验财报，给出基准、乐观、压力情景，解释假设来源和关键敏感因素，导出可修改假设的 Excel 和 Word。缺少可靠输入时明确列待补项。

需要高级分析时继续补充：

> 做反向 DCF，计算目前价格隐含的增长或折现率；对关键假设做蒙特卡洛分析，列明分布、相关性、样本数和 seed，不把模拟分位当预测概率。

支持普通企业分阶段 FCFF、金融企业剩余收益模型；5–15 年逐年经营驱动、稳态回报与再投资联动、风险情景、折现率来源检查、敏感性矩阵、影响排序、反向 DCF、可选相关蒙特卡洛、同行估值快照交叉验证。有股票代码时可取得历史行情及 beta；离线时可导入 CSV。股数、日期、币种不明确时先诊断，不能静默填充。

下载的 Excel 蓝色输入可修改，DCF 和敏感性随公式重算；蒙特卡洛、同行与反向估值章节保留本次快照，修改假设后重新运行工具才能更新这些诊断。Excel 已独立重算验证。

预测目前为经营驱动现金流，不是完整的三张平衡预测财务报表。银行模型仍需要信用风险与监管资本约束补充。资本成本市场参数与预测假设须核验。未进行自动跨币种换算。

`examples/valuation-model/` 提供可以复现的 Excel/Word/JSON/Markdown 示例，所有输入都是明确标注的模拟数据，不代表真实上市公司估值。

全部测试与桌面验收记录见 `docs/valuation-upgrade-verification.json`；研究来源见 `docs/valuation-sources.md`。原对话和配置已保留，升级前备份位于 `backups/before-valuation-upgrade-20261010/`。
