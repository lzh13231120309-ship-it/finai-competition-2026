# 共享资源与安装说明（2026-10-17）

## 包含什么

当前衡知1.6.0的服务端、网页、图标和macOS外壳源码；37个项目Skills及其参考与脚本；141篇本地知识笔记；文档提取MCP、Excel只读复算MCP的源码、依赖和自动配置脚本；项目内财务解析与勾稽参考实现。

五个界面入口为数据结构化提取、财务报告分析、自动化估值建模、研报纠错核查、研报质量评估。37个目录全部随包，其中35个在技能列表可见；产业链影响分析、投资备忘录编制两个退役方向仅保留历史资源，程序不注册为可调用技能，不增加独立参赛功能。内容多不等于专业准确率已通过比赛验收。

## 组员怎么启动

1. 解压整个源码包，安装Python 3.11—3.13（本次实际验证为macOS ARM64 / Python3.13）。不要只下载server或web目录。
2. macOS双击“启动.command”，Windows双击“启动.bat”。首次安装需要联网。也可在项目目录执行 `python3 scripts/start.py`；Windows用 `py scripts/start.py`。
3. 启动器创建主环境和两个MCP独立环境，生成这台电脑自己的连接路径，真实调用文档和Excel工具后启动界面。不要复制其他人的data/config.json。
4. 在设置中填写自己的模型接口密钥，或配置自己的本地模型地址。源代码和资源相同不代表不同模型及硬件的回答、耗时完全一样。
5. 运行后生成的data、虚拟环境、上传文件及日志只保留在接收方本机。故障时先查看本机data/install-status.json；不要把含密钥的完整配置发到GitHub。

macOS扫描OCR需要Xcode Command Line Tools，首次启动会尝试本机编译。跨平台文档插件的扫描OCR还需要系统OCR程序及中文语言数据。未配置时不能承诺扫描件同等可用。首次安装依赖和云端模型调用需要网络；本包不包含模型权重，也不宣称完整离线已验收。

## 两个自动连接的MCP

- financial-doc-extractor：本地文档解析与字段核验，共5个工具，源码和字段定义在integrations/financial-doc-extractor。使用独立.venv-doc-mcp，不使用开发者的插件环境。
- fin-excel-audit：本地Excel读取与公式复算，共7个只读工具，源码与上游许可证在integrations/excel-mcp。使用独立.venv-mcp，默认允许访问当前项目上传、财务产物和导出目录。
- integrations/finsleuth-reference：额外保留的解析、归一、勾稽参考代码，不自动注册为MCP，也不宣称主流程调用了它。依赖按该目录说明另建环境。

## 未包含的内容

原开发者密钥、个人配置、聊天数据库、上传材料、历史分析、日志、备份、其他Agent目录、虚拟环境、模型权重以及用户提供的通知PDF均不共享。对应方法笔记保留，涉及私人原文的内容指纹不携带。分享采用源码安装方式，不复制带开发机绝对路径的原生.app环境。
