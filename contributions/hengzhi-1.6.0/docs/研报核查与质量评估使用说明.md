# 研报核查与质量评估（1.4.0）

在任务中上传研报和原始财报，先对原始财报运行「本地财报核验」。点击「研报核查与评估」，选择一份研报（PDF、Word、Markdown、TXT），或粘贴正文，再明确选择对应财报分析依据。若报告涉及估值或法证发现，可选择同批输入产生的结果。点击开始即可本地生成审阅结果；不需要语言模型或联网市场数据。

结果逐条给出原文行号、科目、期间、口径、归一后的金额、核查依据、证据和修订建议。Word、Excel、JSON、Markdown文件均可下载。原稿不会被改写。

## 如何理解结果

- 已验证：被程序识别的主张与指定本地已核验事实相符；不代表财报内容已获得独立审计。
- 与证据矛盾：同科目、同期间、同口径的数值冲突，或引用指向其他事实；先核原文再修订。
- 待核验：材料缺失、主体/币种冲突、口径不明、解析未能识别、引用尚未登记。不是直接认定错误。
- 模型输出一致：仅证明指定情景与保存模型相符，不能证明预测为事实；仍显示为有条件的待核验。

主张覆盖率的分母是程序已经识别的数字主张，不能说明整篇报告所有句子已检查。扫描件质量、未覆盖科目、英文表格、图表和复杂叙述可能导致遗漏；行号对应提取文本，PDF还应回原页核对。

## 评分与人工评审

内部建议权重：事实30、证据20、方法20、论证15、风险10、表达5。权重不来自赛事官方量表或CFA评分规则。检查项、已评权重、实际得分和覆盖率分别保留；可评部分折算分不能当作完整质量总分。未完成行业适用性、论证深度和表达审阅时，整体总分保持空值，显示「待人工评审」。

审阅者重点判断：事实/预测/意见是否分开；因果关系是否有依据；是否考虑重要反证；模型是否适合行业；预测和市场输入是否过时或使用事后数据；默认参数、重要风险、利益冲突和剩余不确定性是否清楚披露。

方法原则参考[CFA V(A)](https://www.cfainstitute.org/standards/professionals/code-ethics-standards/standards-of-practice-v-a)的合理研究依据及模型验证，以及[CFA V(B)](https://www.cfainstitute.org/standards/professionals/code-ethics-standards/standards-of-practice-v-b)的研究沟通与限制披露。来源登记随应用打包，本地审阅不会为此联网。

## 自动化工作流

在对话中明确「核查这份研报并评估质量」，Agent会读取research-report-review技能，调用audit_report并输出问题表。复杂业务逻辑仍由模型辅助审阅；使用云端模型对话本身需要网络，本地核查按钮可离线运行。

命令行沿用项目finance_cli的audit入口。复用明确分析运行或传入原始财报，输出目录包含审核文件。不把待审核研报作为原始财报依据，不用最近公司自动代替指定来源。保存运行ID、报告正文哈希和参考运行哈希，可以复现核查范围。


## 1.4.1 新增公式与表述核查

明确写出的四则运算、括号、百分比及元/千元/万元/百万元/亿元换算会自动复算，例如 `(100-60)/100=40.00%`。分母为零、单位维度冲突列待核验。仅复算报告操作数，不证明数据来源真实；预测参数等孤立等式不当成公式。审阅文件新增公式复算记录。风险分冒充造假概率、DCF结果证明确定收益的窄范围表述会给出带行号的人工复核提示，否定语境局部处理。
