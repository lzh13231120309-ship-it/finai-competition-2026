# 估值结论校验（1.2.1）

新增 valuation_review，自动列出默认驱动、缺失输入、权益桥接中未核实的零值假设、股数可用性、主要敏感因素与下一步补数建议。计算成功不等于证据充分；条件结果仍保留原模型和导出文件。

同行快照计算后再次生成校验，按股权口径比较 DCF 与 PE/PB/已完成权益桥接的 EV 倍数结果。差异50%仅是项目提示阈值，三家以下标薄样本，企业价值不能直接比较权益价值。不平均相关倍数为一个目标价，不把诊断当概率。

账面净资产仅作会计参照，从模型方法汇总的独立资产估值加权中退出。方法预设权重标注为未校准假设。金融企业剩余收益方法标识已修正，EV/EBITDA 倍数向权益桥接时扣除少数股东权益。

页面、Excel新增结论校验章节，Word/Markdown同步输出；Agent可以直接读取该章节解释，不必反复重建模型。更新技能已核对九个工具副本内容一致，桌面应用用户修改过的技能保留并追加新章节。

验证：558项程序测试、44项子测试、19项界面测试通过。1项可选联网测试跳过。桌面版模型生成、文件下载、中断与继续输入已验收。演示模型位于 examples/valuation-review，全部输入为模拟数据。

方法入口：[Damodaran估值方法](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valuation/val.htm)、[终值方法](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalapproaches.htm)。本文与阈值为本项目原创工程规范，不是该作者规定的唯一实现。
