# 五项联动分析（1.5.0）

在金融大赛本地 Agent 的输入框下方点击「五项联动分析」。先上传材料，再明确选择：原始财报、公告，以及待核查/评估的研报。财报也可复用当前任务已有的分析结果；不要选择其他公司的结果，也不要把研报当作它自己的原始依据。

勾选本轮需要的能力后开始。基础财报只做一次分析；结构化记录、估值及报告事实核查复用这份输入。各阶段保存独立运行编号和下载文件，联动清单记录源文件指纹。

| 能力 | 本轮增强 |
|---|---|
| 数据结构化提取 | 汇集财报标准事实及公告事件记录，保留证据、口径和待核验状态；公告切分不冒充字段原文支持已验证。 |
| 财报分析 | 多个后续步骤复用同一分析；明确显示未通过/待确认勾稽项。原始文件已变化时拒绝复用旧结果。 |
| 自动估值 | 使用专业估值引擎，缺关键输入给补充清单；已启用Excel MCP时，在临时副本清除所有公式缓存后独立复算权益价值。 |
| 研报纠错 | PDF财报来源对账与已有已核验事实对账互补；没有原始依据时明确仅做内部自洽检查。 |
| 质量评估 | 同时保留可观察项评分、覆盖率及事实核查统计，完整人工质量总分保持待评。 |

“已完成”只描述对应机器步骤；“待补充材料”“待复核”“已停止”不会显示成五项全部通过。未知公式、缺少插件和计算分歧均保留实际状态；独立计算一致也不证明输入真实或预测合理。

停止按钮会立即确认请求，当前文件处理结束后停止后续步骤，并保留已经产生的结果。对话中调用联动工具时，停止聊天也会通知联动流程停止后续步骤。新一轮补材料后可以复用明确选择的财报分析，不需要反复重跑全部流程。

联动清单支持JSON、Markdown下载，各阶段另提供自己的结构化结果、估值Excel或质量报告HTML。公告记录、研报问题、专业估值、质量报告的新文件下载入口已修复。

这些按钮对应本地程序，可不调用语言模型完成计算；云端模型聊天仍按原有模型连接配置运行。
