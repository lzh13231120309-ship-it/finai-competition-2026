# 本地 Agent 1.5.1 回复提速

本次修改位于本地 Agent 的 server/agent.py、server/mcp_client.py，已构建原生应用。

## 消除的重复工作

- 新任务直接用输入摘要作为标题，不再在正式回答前额外调用一次模型（旧实现最多等待10秒）。已有自定义标题保留。
- 没有新附件的追问，不再因为出现“年报、现金流”等词就自动分析任务内全部历史文件。模型仍能调用全部金融工具，按需读取已核验结果或重新分析。
- 新上传且要求财报分析的附件仍执行程序预检；将结果明确告知模型，避免再做一遍目录查看和整份分析。
- 不同MCP服务器同时准备，工具顺序仍按配置保留。移除同一轮中先启动、再发现工具导致的失败重复尝试；失败原因仍显示。取消连接时收回所有尚未完成的启动任务。
- 收紧任务范围：完整分析才交付完整文件；单项追问按需补证和解释，不自动扩为五项全流程，也不重复导出文件。

## 保留的能力

模型选择、输出额度、最大分析步数、财务取数和核验、估值引擎、研究报告核查与质量评估均保留。复用仍受文件来源、公司、期间和口径约束；不把最近一次结果无条件当作当前答案。

## 验证边界

`response-speed-benchmark.json` 使用同样的本地即时模型替身，给旧版标题请求或重复财报处理设置150毫秒延迟，分别对比三次中位数。它证明两段额外等待已移除，不能代表真实云端回答加速比例。复杂分析的时间仍受模型服务、网络、文档规模和必要核验次数影响。

回归命令：`.venv/bin/python -m pytest tests -q`；界面测试：`node --test tests/*.cjs`。
